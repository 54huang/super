# 3 · 逐镜提示词（可直接复制）

> 格式：**N14 五段式**（主体 / 风格 / 时间线 / BGM / 限制）。
> 每条的「风格」段都写「全局风格块 + 附加项」，复制时把下面的【全局风格块】整段替换进去即可。
> 七条共用同一套锚点，**不要改任何一个形容词**，改了就会漂。

---

## 【全局风格块】（复制时整段塞进每条的"风格"位置）

```
深空蓝渐变背景（顶部 #0B1220，底部 #05070C），细青色透视网格地板，等宽字体风格的半透明代码卡片（#0F172A、60% 不透明、2px 青色 #22D3EE 描边），左上 45° 冷白体积光，轻微辉光与极轻胶片颗粒，9:16 竖构图，主体居中偏上（纵向 38%），底部 18% 留空
```

## 【负面清单】（每条末尾追加，一段话）

```
不要出现任何可读文字、字母、数字或乱码字符；不要水印、台标、logo；不要真人面部与手部；不要镜头抖动；不要过曝与大面积炫光；不要塑料感与油画感；不要画面撕裂与帧间跳变；不要风格漂移（底色、网格密度、描边粗细必须与其他镜头完全一致）；主体不要被上下裁切
```

---

## S01 · 0–4s 钩子：立方体悬浮

```
主体：一个 128px 青色发光立方体，磨砂玻璃质感，棱边 2px 辉光，表面有极细网格纹理，内部有缓慢流动的白色粒子；立方体悬浮在画面上方三分之一处，下方是细青色透视网格地板
风格：全局风格块 + 仅一个光源（左上 45° 冷白体积光），立方体投在地板上的光斑柔和不锐利
时间线：0–1s 立方体静止悬浮，内部粒子缓慢流动；1–3s 立方体绕 Y 轴缓慢自转 30°；3–4s 镜头以 1.05 倍速缓慢推近，立方体最终占画面高度约 35%
BGM：低频氛围垫 60BPM；第 3.5 秒一次轻微的电子提示音；无人声
限制：9:16 竖构图；不出现真人；不出现任何可读文字；底部 18% 保持空镜；不要镜头抖动；不要字幕；不要过曝
```

**首帧（图生视频用）**：静止的青色立方体悬浮在网格地板上方，内部粒子凝固，无运动模糊。

---

## S02 · 4–8s 举证：代码卡片滑入

```
主体：一块半透明代码卡片从画面右侧滑入，停在纵向 35% 处，卡片 720×420px、圆角 16px、四角有细刻度线；卡片内有三行青色发光短线（上长、中中、下短）；左下角是同款立方体缩小到 20%，旁边一枚白色文档图标（仅三条横线）
风格：全局风格块 + 卡片背面有微弱内发光；卡片保持正面平行，不做 3D 倾斜
时间线：0–1s 卡片从右侧缓出滑入；1–2.5s 第一行短线亮度由 20% 升到 100%；2.5–3.5s 第二行亮起；3.5–4s 第三行亮起，立方体同步轻微下沉
BGM：同前，叠加极轻的键盘敲击环境音（每秒 3 下）；无人声
限制：9:16；卡片内不允许出现任何可读字符或代码文字；不出现真人；底部 18% 留空；不要镜头抖动；不要卡片倾斜或翻转
```

---

## S03 · 8–12s 制造缺口：异常炸开

```
主体：红色裂纹光（#F43F5E）从代码卡片中部炸开并沿对角线扩散，碎片悬停在半空；立方体表面同步出现两道裂纹，裂纹边缘有熔融感
风格：全局风格块 + 轻微色散（RGB 分离 1px），整体曝光下降 15%，红光是画面唯一暖色
时间线：0–0.05s（约 2 帧）卡片中部一次强烈白光；0.05–2s 裂纹沿对角线扩散到卡片边缘；2–3s 碎片悬停并轻微飘动；3–4s 立方体表面裂纹亮起，画面轻微向左下偏移 2px
BGM：低频下坠音；第 0.05 秒一次短促失真音；无人声
限制：9:16；不出现真人；不要火光与烟雾；不要血腥；镜头只允许 1–2px 呼吸感抖动，不要剧烈晃动；底部 18% 留空
```

---

## S04 · 12–16s 反转：close 标签浮现

```
主体：裂纹停止扩散并逐渐暗下去；一个白色圆角标签从立方体下方浮现，标签内只有一个手绘风格的勾（无文字）；一条细白线从标签连到立方体底部；立方体裂纹闭合，表面恢复完整
风格：全局风格块 + 曝光回到正常，红色只残留余晖；标签有轻微毛玻璃质感
时间线：0–1s 裂纹停止，红色亮度降到 30%；1–2s 标签从下方 20px 处浮现并轻微回弹；2–3.5s 白线从左到右生长并连上立方体底部；3.5–4s 镜头缓慢拉远 8%
BGM：低频上行为主；第 2 秒一次清脆的"确认"音效；无人声
限制：9:16；标签内不要生成任何字母或数字（只保留勾）；不出现真人；底部 18% 留空；不要镜头抖动；不要过曝
```

---

## S05 · 16–22s 机制：下坠与碎裂（全片唯一长镜）

```
主体：立方体从悬浮状态开始下坠，依次穿过三层半透明的青色"作用域"边框（层间距约 200px），穿过时边框亮起；立方体落到画面纵向 70% 处瞬间碎裂成 200–300 颗小粒子，粒子带极短拖尾
风格：全局风格块 + 三层边框透明度分别为 0.6 / 0.4 / 0.25 以区分景深；粒子是点光，不是烟雾
时间线：0–0.5s 立方体加速下坠；0.5–2.5s 穿过第一、二层，边框依次亮起；2.5–4s 穿过第三层（最亮），立方体出现裂纹；4–5.5s 落地碎裂，粒子向外扩散后缓慢回落；5.5–6s 粒子静止悬浮，画面轻微降速
BGM：每穿过一层一次鼓点（共三次），落地一次低频冲击；无人声
限制：9:16；不出现真人；粒子不要烟雾化；慢动作不超过 0.5 秒；底部 18% 留空；不要文字
```

**首帧（图生视频用）**：立方体在顶层边框上方静止悬浮，下方三层边框清晰可见，无运动模糊。

---

## S06 · 22–26s 命名：粒子重组成结构图

```
主体：悬浮的粒子重新聚合成一个纵向分栏结构图：左栏两层堆叠方块代表"栈"，右栏一个带光晕的圆形代表"堆"，两栏之间有一条发光中线，中线一端连着一枚白色文档图标
风格：全局风格块 + 结构线为 2px 青色、节点带轻微辉光；整体曝光稳定
时间线：0–1s 粒子向中心汇聚；1–2.5s 分栏轮廓逐渐描出（左先右后）；2.5–3.5s 中线从左亮到右并连上文档图标；3.5–4s 镜头缓慢环绕 15°
BGM：持续的合成弦乐垫；第 2 秒一次上升音；无人声
限制：9:16；结构图上不生成任何可读文字（"栈""堆"由后期字幕叠加）；不出现真人；底部 18% 留空；不要镜头晃动
```

---

## S07 · 26–30s 收尾：结构收束

```
主体：结构图整体收束，折叠成三层横向发光台阶（自下而上逐层变小），台阶顶部悬停一个微缩立方体，画面中心形成一个稳定的三角形光域
风格：全局风格块 + 收尾提亮 10%，网格地板略微向前推进形成"落地"感；不新增任何元素
时间线：0–1s 结构图折叠收束；1–2s 三层台阶自下而上依次亮起；2–3s 微缩立方体落到顶层并静止；3–4s 镜头固定，光域做一次亮度呼吸（100%→90%→100%）
BGM：最后一个和弦收尾；第 3 秒后留 1 秒静音；无人声
限制：9:16；不生成任何文字（"RAII"由后期落版叠加）；不出现真人；底部 18% 留空；不要镜头运动；不要新增元素
```

**首帧（图生视频用）**：三层台阶已成形，微缩立方体悬停在最上层上方约 40px 处。

## 换题材怎么改（这套结构可以直接复用）

把「立方体」换掉，其余不动：

| 你的题材 | 主体替换成 | 道具替换成 | 异常替换成 |
|---|---|---|---|
| 内存泄漏 | 一个不断膨胀的半透明球 | 内存条图标 | 红色滴落光 |
| 多线程竞争 | 两个互相撞的立方体 | 锁图标 | 橙色火花 |
| 智能指针 | 一条链条牵着立方体 | 链环 | 链条断裂光 |
| 你的毕设项目 | 你的系统架构方块（3 层堆叠） | React / C++ 图标替代 | 编译报错红光 |

## 平台适配

- **Seedance / 即梦**：以上五段式直接用。
- **海螺 H3**：把「首帧」那句单独作为一段前置，运动描述另起一段 —— H3 对"这一帧"和"怎么动"分得很开。
- **Veo 3**：把 BGM 段改成「声音」段，写明"环境音 + 是否有人声 + 台词原文（本片无台词）"，并把 `9:16` 写在限制段开头。
- **想要六段式**（主体/动作/环境/镜头/光线/约束）时：主体←主体，动作+镜头←时间线（拆成两句），环境←背景与网格地板，光线←风格段里的光源，约束←限制 + 负面清单。**只是换包装，内容一一对应**。

# 附：美术方向 B ·「制图台」（与渲染器 v2 对齐）

> 上面的七条是**方案 A（深空蓝）**。如果你更喜欢三镜渲染工作台里那版纸墨质感，七条提示词要换的不是结构，而是 **风格段 + 负面清单** 两处。
> 换美术方向时最容易犯的错：只改了正面描述、没改负面词 —— 模型会继续往"科技蓝 + 发光"跑。

## 【全局风格块 · 方案 B】

```
暖白纸底（#F4EFE3），5mm 细方格与 25mm 粗方格叠加，纸面有极轻印刷颗粒与不均匀受光；墨色线稿（#1B1A17），2px 主框 + 1px 辅助线；工程制图语言：图框、图注（CODE-01 / FIG.S03）、尺寸标注、细引线；唯一强调色朱红（#BE3A2B），仅用于批注、波浪红线与校对章；纸片投影极浅，无环境光渲染；9:16 竖构图，主体居中偏上，底部 18% 留空
```

## 【负面清单 · 方案 B】（务必整段替换掉 A 版的）

```
不要深色背景、不要青蓝渐变、不要霓虹与辉光、不要发光粒子、不要玻璃/塑料质感、不要 3D 渲染感与高光反射、不要散景光斑、不要可读文字与乱码字符（文字全部后期叠）、不要水印、不要真人、不要镜头抖动、不要过曝、不要画面撕裂、不要风格漂移（纸色、网格密度、线宽必须与其他镜头一致）
```

## 逐镜怎么改（只改风格段，其余不动）

| 镜 | 方案 A 的风格段 | 方案 B 换成 |
|---|---|---|
| S01 | 深空蓝 + 体积光 + 辉光立方体 | 一张纸上的线稿纸盒（等轴测），纸面方格透出，投影极浅 |
| S02 | 半透明代码卡片 + 青色描边 | 一张贴上去的代码图纸（图框 + 图注），三行短线上压着红色校对线 |
| S04 | ✓close 标签 + 白线生长 | 红色校对章落在图纸角落 + 引线指向 close 调用点 |
| S07 | 三层发光台阶 + 光域呼吸 | 三张图纸叠成一摞（俯视透视），最上层盖一枚红章 |

> 判断标准：**方案 A 靠光，方案 B 靠线和字**。方案 B 的画面信息量更大、更"人做过"，但也更依赖精确的排版；S01/S07 这类需要氛围的镜头，方案 A 反而更省事。混用会打架，二选一。
