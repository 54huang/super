# 4 · 出片与验收清单

> 用法：每生成一镜，回来对照本页。**先按翻车表排查，再决定是否重生成** —— 大部分问题不是模型不行，是提示词漏了维度。

## 一、生成参数

| 项 | 值 | 说明 |
|---|---|---|
| 画幅 | 9:16 / 1080×1920 | 不要让模型出横屏再裁，裁完构图全毁 |
| 时长 | 4s ×6 + 6s ×1 | 必须落在平台档位（4/6/8/10） |
| 帧率 | 30fps | 竖屏够用，60fps 徒增成本 |
| 生成方式 | 先图生视频 | 用「首帧」那句先生成静帧，确认构图后再动 |
| 抽卡轮次 | 每镜 3–4 次 | S03/S05 属高危镜，留到 6 次 |
| 后期 | 代码 / 字幕 / RAII 落版全部后期叠加 | 画面里绝不让模型写文字 |

## 二、翻车对照表（N06 负面词 + 实战补充）

| 现象 | 真实原因 | 修法 |
|---|---|---|
| 立方体每镜长得不一样 | 主体描述换了同义词 | 主体锚点逐字复制，一个字都别改 |
| 背景底色一镜深一镜浅 | 风格块被改写或漏写 | 全局风格块整段粘贴，不要手打 |
| 出现乱码文字 | 提示词里出现"代码/文字"意图 | 删掉所有可能诱导文字的表述，负面清单必带 |
| 运动像 PPT（只有缩放） | 时间线只写了"推近" | 时间线补"物体自身动作"，镜头运动是第二位 |
| 立方体飘着走（物理不对） | 没写重力与接触面 | 时间线里加"落地""接触""回弹"等物理词 |
| 碎裂变成烟雾 | 用了"粒子爆发"这类模糊词 | 改成"200–300 颗点光小粒子，带极短拖尾" |
| 竖屏主体被切头/切底 | 没写构图锚点 | 补"主体居中偏上（纵向 38%），底部 18% 留空" |
| 镜头抖得像地震 | 手持描述过头 | 写"仅 1–2px 呼吸感"，不要"手持晃动" |
| 色调突然变暖 | 引入了第二个光源 | 明确"单光源，左上 45° 冷白" |

## 三、验收打勾表（N19 的 SOP 思路）

### 单镜（每镜都过）

- [ ] 底色、网格密度、描边粗细与本片其他镜头**肉眼一致**
- [ ] 立方体尺寸比例正确（S01 约 35% 画高，S02 约 20%）
- [ ] 画面内无任何可读文字、无水印
- [ ] 主体未进入底部 18% 与右侧 12% 安全区
- [ ] 运动方向与时间线一致（推近/拉远/下坠/环绕）
- [ ] 无帧间跳变、无形态融化

### 全片（拼起来之后）

- [ ] 7 镜时长合计 = 30.000 秒，无空洞无重叠
- [ ] 前 3 秒有"疑问 + 运动"，完播第一关通过
- [ ] 每 8 秒内至少一次视觉变化（景别/色调/构图）
- [ ] 字幕不越底部 18%，不与抖音 UI 重叠
- [ ] 红色只出现在 S03（唯一暖色），没有蔓延到其他镜头
- [ ] 音频：BGM 三次鼓点对齐 S05 三层边框，落地冲击对齐碎裂帧

## 五、成本参考（按每镜平均 4 次抽卡估）

| 镜 | 抽卡次数 | 备注 |
|---|--:|---|
| S01 / S02 / S04 / S06 / S07 | 3–4 | 结构明确，稳定 |
| S03 | 5–6 | 爆裂类效果易崩 |
| S05 | 5–6 | 长镜 + 碎裂 + 下坠，三重难 |
