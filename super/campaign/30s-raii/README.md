# 实战演练 · 30 秒竖屏知识口播《析构函数不是免费的午餐》

> 目的：验证「节点库」能不能真的把一句话变成可出片的东西。
> 结论：能。链路是 **N10 的时间码切镜 → N14 的五段式 → N06 的四维与负面词 → N08 的画风锚点 → N19 的验收表**。

- 题材：C++ RAII（析构函数自动释放资源）
- 规格：9:16 / 1080×1920 / 30fps / 总时长 30 秒 / 7 个镜头
- 文案：125 字，约 4.2 字/秒，符合讲解类口播语速
- 出片方式：两条都能走 —— ①AI 生成（Seedance/即梦，本文件按此写）②代码出片（Remotion/Canvas，见文末映射）

## 文件顺序

| 文件 | 对应节点 | 干什么 |
|---|---|---|
| `1_口播稿与SRT.md` | N10 | 先定旁白，再导出标准 SRT，镜头时长由时间码算出来 |
| `2_分镜表.md` | N10 + N05 | 7 镜的景别/机位/运镜/功能/字幕，对齐 4 秒档位 |
| `3_逐镜提示词.md` | N14 + N06 + N08 | 七条可直接复制的五段式，共用一套风格块与负面清单 |
| `4_出片与验收清单.md` | N19 + N06 | 生成参数、翻车对照表、验收打勾表 |
| `../../renderer/index.html` | N22 + N21 | **真帧**：S03/S05/S06 三镜用代码逐帧渲染，可播放、可导出 PNG 序列 |

## 这次演练守住的 5 条规矩

1. **时间码闭合**：7 镜 4+4+4+4+6+4+4 = 30，无缝覆盖、不重叠、不留空洞。
2. **档位取整**：全部镜头落在 4 秒 / 6 秒（平台常见档位），没有 5.5 秒这种写法。
3. **一镜一功能**：钩子 / 举证 / 制造问题 / 反转 / 机制 / 命名 / 收尾，功能重复的镜头直接砍。
4. **画风锚点全局复用**：底色、网格、字体、描边、留白，每镜逐字相同 —— 换成同义词就会漂。
5. **画面内不生成可读文字**：代码行只用"发光短线"表示，真实代码与字幕全部后期叠。这条是知识类视频不翻车的关键。

## 如果换成"非生成式"出片（第七章那条路）

同一个分镜表可以整段交给代码渲染，改动只有一处：

| 镜头 | AI 生成 | 换成代码出片时 |
|---|---|---|
| S01 立方体悬浮 | 提示词即可 | Canvas/Three.js 画立方体 + 呼吸光 |
| S02 代码卡片滑入 | 提示词即可 | HTML 卡片 + GSAP 时间轴，代码可真实可选 |
| S03 裂纹/异常 | 提示词（易崩） | SVG 裂纹路径 + 抖动滤镜，稳得多 |
| S04 close 标签浮现 | 提示词即可 | GSAP 描边动画 |
| S05 下坠碎裂 | 提示词（最易崩） | Canvas 粒子系统，物理可控 |
| S06 栈/堆结构图 | 提示词（易乱） | Remotion/Motion Canvas 画分层，必对 |
| S07 RAII 落版 | 提示词即可 | 纯 CSS/GSAP |

**判断标准**：画面里"有精确结构的图形"（结构图、代码、数据）交给代码；"需要氛围与体积感"的（S01/S03 光效）交给 AI。混剪时用同一时间轴对齐即可。
