# ADR-006：第三版换仪器，不再换版面

## 状态

已采纳。v1、v2 全部保留，v3 是并列的第三条路线，不是替换。

## 背景

前两版都被同一个问题卡住：

| 版本 | 介质 | 结果 |
|---|---|---|
| v1 深空蓝 | 渐变底 + 发光立方体 + 粒子 | 技术上全绿，被判「太普通」 |
| v2 制图台 | 暖白纸 + 墨线 + 朱红批注 | 换掉了 v1 的平庸，但仍是**版面** |

v2 的问题不在执行，在**表达类型**。它把信息排布在一张纸上：图框、图注、尺寸线、批注。这套语汇擅长说"这个对象长什么样"，不擅长说"这两件事在时间上是否对应"。

而 RAII 的全部内容就是后者：构造与析构必须配对，异常路径上也不能漏。这是一个**双序列的时间关系**，不是一张静态版面能说尽的。v2 能做的是"在纸上写出 `~File()` 被调用了"，画不出"如果没有 RAII，另一条线会怎么样"。

第三个触发条件是镜头数。从 3 镜扩到 8 镜，如果八镜都是同一张纸上的不同排版，看到第五镜就会疲劳——因为变化只发生在内容，不发生在**观看方式**。

## 决定

换**介质类型**，不是换配色：

> 前两版是"版面"，第三版是"仪器"。

具体落在示波器上：

- **横轴就是时间。** 不需要比喻，示波器的物理意义就是"电压随时间的函数"。
- **双通道叠加是论点的形状。** CH1 是 RAII，CH2 是手动管理。同一场异常，CH1 回到基线，CH2 停在半空。两条线的落差本身就是结论，不需要额外解释。
- **八镜是一条波形生命史。** 上电 → 构造 → 正常析构 → 异常 → 栈展开 → 对照上场 → 泄漏定格 → 读数。镜头之间不是并列关系，是同一事件的推进。

两个技术选择同时定下来：

1. **辉光用三段描边，不用 `shadowBlur`。** `shadowBlur` 是软件高斯核，成本随"面积 × 核半径"上升。同一个视觉效果可以用 5.5px / 2.6px / 1px 三层不同透明度的描边叠出来，成本是常数。
2. **波形噪声用正弦叠加，不用 `Math.random`。** 随机数会让同一时刻渲染出不同帧，逐帧导出时整条波形会抖。用 `sin(t·137.5)` 这类固定频率叠加，既有信号的毛刺感，又完全确定。

## 后果

**代价一：深色画面在信息流里吃亏。** 抖音的浏览环境偏亮，深色封面在缩略图状态下对比度低，"停下来"的能力弱于 v2 的暖白纸。这是这一版最实际的损失。

**代价二：有阅读门槛。** 时基、触发、通道、"停在半空"——不懂示波器的人可能看不出 CH2 那条线意味着什么。v2 的纸面批注是自解释的，v3 的波形不是。**这是用表达力换了普适性。**

**代价三：不能直接替换原片。** 八镜 × 4 秒 = 32 秒，与 30 秒的原片时间码不对齐。它是一条独立实验片，要接回原片得重排时间轴。

**代价四：单镜信息密度下降。** v2 一帧里能放图框、代码、三处批注、校对章；v3 一帧通常只有一条波形加两行读数。动态过程更清楚，静态信息更少。

**代价五：中文可读性变弱。** 荧光绿配黑底，中文的字形细节不如墨色压在纸上清楚。21px 以下的正文在低亮度屏幕上会糊。

保留的收益：**这是三版里唯一能表达"对比"的一版。** v2 能说"RAII 会析构"，说不了"不 RAII 会怎样"。CH2 那条不落的线，是前两版都做不到的论证。
