# ADR-004 · 美术方向从「深空蓝」改为「制图台」

**状态**：已采纳（2026-10-28），v1 保留在 `renderer/legacy/`

## 背景

v1 的美术方向是：深空蓝渐变背景 + 青色透视网格 + 发光线框立方体 + 粒子爆发。

技术上没有问题——它跑得很稳，构图也对。但拿到第一眼反馈是：**太普通**。

这个判断是对的。v1 的元素组合（青蓝渐变、辉光、粒子、线框几何）是 2026 年 AIGC 内容的默认皮肤，几乎所有"科技感"模板都长这样。问题不在完成度，在**没有作者痕迹**：观众看完记不住是谁做的。

## 决定

**不换配色，换介质**。从"三维虚空里发光的物体"改成"一张纸上的图"，美术方向命名为「制图台」：

| 维度 | v1 | v2 |
|---|---|---|
| 介质 | 三维虚空 + 体积光 | 暖白纸 `#F4EFE3` + 5mm 方格 + 印刷颗粒 |
| 线条 | 发光描边 | 墨线 `#1B1A17`，2.5px 主框 / 1px 辅助 |
| 强调色 | 青色霓虹铺满画面 | 朱红 `#BE3A2B`，**面积 <3%**，只用于批注与校对章 |
| 信息 | 装饰 | 图框、图注、尺寸标注、引线、**真实代码** |
| 运动 | 缩放、环绕、粒子 | 擦除进入、打字机、dash 描线、落章回弹 |

同时把视觉语言**借**过来而不是发明：工程制图的图框/图注/尺寸标注、校对符号的波浪线与红章、手写批注。

## 后果

- **收益**：反差来自"冷内容 × 暖印刷"，在信息流里有辨识度；纸自带叙事——代码写在纸上，批注是人的动作。
- **收益**：信息密度大幅提升。真代码 + 图注 + 批注，画面每个角落都有东西可读；空画面靠光效撑，密画面靠信息撑。
- **代价**：**换了美术方向，AI 那四个镜头的提示词必须同步换**，否则混剪会打架。为此在 `3_逐镜提示词.md` 文末补了「方案 B」：新的全局风格块 + 整套负面清单（不换负面词，模型会继续往科技蓝跑）。
- **代价**：v2 依赖精确排版，比 v1 更"脆"——字号、行距、对齐错一点就显脏。用 `specs/style-tokens.json` 把参数固定下来，并用测试防止代码与文档漂移。
- **代价**：两套美术方向并存，需要明确"二选一，不混用"。在 `specs/shots.json` 的 `artDirections` 里用 `status: active|legacy` 表达。

## 附注

这次改版能在一轮内完成，是因为 `tests/tokens.test.mjs` 会检查"文档里的色值必须出现在源码里"。没有这个约束，改配色几乎必然漂移。
