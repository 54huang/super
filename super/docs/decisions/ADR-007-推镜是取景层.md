# ADR-007：推镜是取景层，不是纸面层

## 状态

已采纳。第一版的"全片零镜头运动"保留为 06 案例卡里的留档判断，不是错误，只是没有推到底。

## 背景

做 06 年度计划表那一版时，第一版的判断是：**全片零镜头运动。**

理由是：纸是钉在桌上的，镜头一动，观众就会觉得"这是拍摄"，而整支片要的是"这是一张真的表"。固定镜头 + 手在纸上动，是这张纸能被当成真的前提。

这个理由有一半是对的，但推出来的结论是错的：

> 完整不等于不能靠近。真正要守的是"十二行不能少"，不是"框必须一直是全纸"。

两个触发条件让它站不住了：

1. **用户要求加局部缩放做特写。** 第三镜要读"选品 / 报价 / 方案"三个字压在一个 312×74 的框里，字号 32px。在 1080 宽的竖屏上，观众看到的是三个模糊的方块——这个镜头的论点（挤）根本传达不到。推镜在这里不是美化，是**信息能不能到达**的问题。
2. **4 秒的镜头做不了"全景 → 特写"。** 第一版的时间码是 `6+4+8+6×7`（唯一解，因为逐句量过旁白秒数）。从全景推到能读字的距离，4 秒里做完会显得仓促、像手抖。所以先把十镜统一成 6 秒，代价是第三镜删一个字（5.50 → 5.46 秒，余量 0.02 秒）。

## 决定

加一层**相机**，包在 `shot.draw` 外面，笔画代码一行不改：

```
cam: { x0, y0, z0,  x1, y1, z1,  sub: {x, y, w, h} }
```

- `z` 是放大倍数，`(x, y)` 是落在画面中心的**纸面坐标**，两端之间用 `smoothstep` 插值
- `sub` 是"这一镜的主体矩形"，断言只盯它

三条硬约束，全部写成断言：

| 约束 | 为什么 |
|---|---|
| `1 ≤ z ≤ 1.45` | 上限不是审美决定的，是算出来的：竖屏 1920 高、行区只占 946，z=1.42 时可视 1352，**刚够装下整块行区**。再紧，骨架就出画了 |
| 帧间 \|Δz\| ≤ 0.01 且只推不退 | 跳变会被读成"这里切了一个新镜头"；推到一半往回退，观众会看出"镜头在找东西" |
| 推到最紧时十二条行线全在画面内 | 这是 06 的立论。行线出画 = 换了一张短一点的表 |

第一个版本的断言写错了，值得记下来：

> 当时的断言是「任何一行字经相机变换后都不能出画」。跑出来第三镜报错：「好礼乐」被推出画面。
>
> 但那是**对的**——镜头往右下推进那个框，表头本来就该从左边出画。

后来改成「这一镜声明的 `sub` 矩形全程在画面内」。**出画不是错，出画的不是主体才是错。**

## 后果

**代价一：第三、四镜的月份号整列出画。** 1.40 倍下画面只有 771px 宽，而"09 月的圈"（x=190）和"节前两周的框"（x=636–948）相距 758px，装不下两个。行线还在（断言守着），但"这是几月"要靠第三镜开头 0.8 秒交代。想同时保住两者，上限只能到 1.15——那就不算特写了。**这是物理约束，不是取舍失当。**

**代价二：码率翻了近五倍。** 成片从 3.37MB 涨到 16.0MB（456 → 2020 kb/s）。零运动时帧间几乎不变，编码器几乎不花码率；一旦全片都在缓推，每一帧都是新信息。60 秒竖屏 16MB 仍可接受，但如果要做 3 分钟以上的片，得重新算。

**代价三：第三镜的旁白被压到贴着窗口。** 5.46s 塞进 6s，余量 0.02s，靠 TTS 1.01 倍速（不可闻）换来的。它是全片唯一一句贴边的，改稿要先动别处。

**代价四：所有"纸上的痕迹"必须变成可重画的函数。** 加推镜之后才暴露出：第一镜（正确地）写下的「春节 / 端午 / 中秋」到了第三镜就消失了——因为各镜只重画圈、不重画字。零运动时这个缺口在缩略图上根本看不出来，推镜把它放大到藏不住。修法是 `peakMarks()`：种子和线宽与第一镜完全一致，画出来是同一笔。

> **推镜不会制造连续性错误，它只会把已经存在的连续性错误放大到藏不住。**

**代价五：页脚说明被迫换坐标系。** 它原本画在纸面 y=1570，离平台 UI 区（1574）只有 4px——零运动时是"能放就放"的侥幸。改到屏幕坐标 1510（不跟缩放）之后又撞了第二回：推镜把 12 月那行推到 1526/1531，正好压在这行字上。最后是两头一起让才空出来。现在 `CAPTION_Y`（屏幕）和 `P`（纸面）故意分开命名，两种坐标不混在一个对象里。

保留的收益：**这是唯一一版能让人"读清一个细节"的画面。** 全景负责"这是同一张表"，特写负责"这个框里到底挤成什么样"，两者在一次连续的推轨里完成切换，观众不会觉得换了主体。
