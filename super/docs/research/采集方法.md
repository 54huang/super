# 采集方法（可复现）

## 一、检索

- 工具：GitHub Search API（`/search/repositories`），按 `stars` 降序，每词取 30 条
- 词表：36 组，分 4 批执行。分四类：

  | 类别 | 示例检索词 |
  |---|---|
  | 模型与提示词 | `sora prompt` `veo3 prompt` `ai video prompt` `kling ai prompt` `text to video prompt` |
  | 镜头与分镜 | `cinematic prompt` `camera movement prompt` `storyboard prompt` `shot list` `cinematography shot list` |
  | 生产流程 | `short video script` `短视频` `视频 提示词` `douyin` `ai filmmaking` |
  | 非生成式出片 | `remotion` `manim animation` `motion-canvas` `lottie animation` `anime.js` |

- 去重键：`full_name`
- 结果：**675 个去重仓库**

## 二、限流与网络

- 未认证的 search API 限流 **10 次/分钟**；批量脚本在每次请求后 `sleep 6.5s`。
- 未认证的 core API 限流 **60 次/小时**，用于逐仓核对（`/repos/{owner}/{repo}/contents/` 与 `/readme`）。
- 本机环境下 `raw.githubusercontent.com` 不可达，改用 API 的 `/readme` 端点（返回 base64）取 README 首 2.5KB。

## 三、筛选

四条标准，任一不满足即淘汰：

1. 交付物是**文本资产**（md / 词表 / 模板 / Skill），不是权重、不是成片；
2. 有**镜头维度**（景别/机位/运镜/时长）；
3. 能**原样粘贴**进模型，不需要先部署服务；
4. **2026 年仍有提交**，或内容不过期。

结果：**50 个仓库**，其中 **24 个**标记为节点（"打开就能抄走一段可用内容"）。

## 四、快照字段

`repos.snapshot.json` 每条记录：

| 字段 | 含义 | 来源 |
|---|---|---|
| `id` | 1–50，与全仓清单编号一致 | 人工排序（按分类、再按星数） |
| `repo` | `owner/name` | API `full_name` |
| `url` | 仓库地址 | API `html_url` |
| `category` | 8 个分类之一 | 人工判断 |
| `stars` / `starsLabel` | 精确星数 / 展示用近似值 | API `stargazers_count` |
| `language` | 主语言 | API `language` |
| `pushedAt` / `createdAt` | 最近提交 / 创建日期 | API |
| `node` | `N01`–`N24` 或 `null` | 人工判断 |
| `purpose` | 一句话用途（**取舍依据**，不是官方描述） | 人工撰写 |
| `topics` | 仓库 topics（最多 6 个） | API |

## 五、复查

星数与更新时间会过期。建议每季度：

1. 按 `repos.snapshot.json` 的 `repo` 批量请求 `https://api.github.com/repos/{repo}`；
2. 对比 `stars` 与 `pushedAt`，把一年多没提交的标进 `library/*/README.md` 的备注；
3. 更新 `generatedAt` 与 `README.md` 里的快照日期；
4. 跑 `npm test`，确认数量与编号未被破坏。

## 六、已知偏差

- **可灵（Kling）没有专用库入库**：本轮检索到的可灵相关仓基本是 API 中转站或低质转载。已在 `library/05_单模型专用库/Kling与海螺/README.md` 注明，并给出替代方案（用 02 的运镜词表 + 05 的五段式骨架）。
- **6 个仓库只核到仓库层**，未逐层核到子目录（N09/N12/N15/N16/N19/N20/N23 中的部分），笔记里统一标注"以根 README 为入口"。
- 星数是热度，不是匹配度。48 星的运镜库对"镜头控制"的价值高于 2.8k 星的案例库——筛选时以标准为准，不以星数为准。
