# 案例 05 · 暖摊灯箱

**状态：现役。** 十镜 W01–W10，60 秒竖屏，为一条 B2B 短片做的。实现不在本仓库——它在交付工程 `aigc_video` 里，主文件 `warm-renderer.js`（约 1100 行）。这张卡记录的是画法和取舍，不是代码。

## 一句话

背光亚克力灯箱板 + 粗记号笔 + 胶带贴纸条：板子自己是光源，字和纸都是**贴**在光前面的东西。

## 视觉构成

| 项 | 值 |
|---|---|
| 板面 | 纵向五档 `#FFF7E2` → `#F8E4BA` → `#E9C892` → `#F8E4BA` → `#FFF7E2`（上下亮、中间沉，因为灯管在板后上下两条） |
| 四角压暗 | 径向 `#6B4620`，中心 0 → 0.46 处 0.07 → 0.78 处 0.34 → 边缘 0.78 |
| 灯管 | 管身 `#FFD98A`，芯 `#FFF7E4` |
| 记号墨 | `#2A1B10` — 正文、标题、划掉 |
| 纸（正面） | `#FBF2E2`，中缝 `#DCC49A` |
| 纸（背面） | `#C9A468` — 比板面**暗**，见「关键技术点」第 4 条 |
| 胶带 | `#F0D68C`，58×27px，±0.42rad |
| 蒸汽 | `#FFFDF5`（不是纯白，纯白在暖底上发青） |
| 辣椒红 | `#C8452B` — 只做批注 |
| 字号阶梯 | 150 / 96 / 72 / 56 / 44 / 34 / 27（七档，没有中间值） |
| 安全区 | x 72–1008，y 210–1600（底部 18% 让给平台 UI） |
| 强调色预算 | 单处 ≤3600px²、全帧 ≤12000px²（0.58%），断言卡 3% |
| 十镜时长 | 6 / 6 / 6 / 6 / 8 / 6 / 6 / 6 / 6 / 4 = 60 秒 |
| 单帧成本 | 380–450ms（其中 97% 是 PNG 编码，不是绘制） |

## 实现入口

- 主文件 `warm-renderer.js`：十镜脚本 + 六种画法，导出 `window.Warm`
- 六种画法：`drawPanel`（板面）/ `markerStroke`（笔迹）/ `markerText` + `writeChars`（手写字）/ `paperStrip` + `note`（贴纸）/ `steam`（蒸汽）/ `bag` + `hand`（实物剪影）
- 引擎导出：`init` `select` `seek` `toggle` `onChange` `exportFrame` `exportSequence` `renderAt`，状态里两个开关 `safe` / `watermark`
- 工作台：切镜、播放 / 暂停 / 循环、拖时间轴到毫秒、← → 逐帧、安全区与水印开关、导出当前帧 PNG、导出整镜序列
- 命令行出片：`node scripts/render-offline.mjs --style v5 --all --out frames`，支持 `--from N --to M` 断点续渲、`--frame <毫秒>` 单帧调试
- 配音与配乐也是算出来的：`tts-align.mjs`（逐句合成 + 按实测秒数摆位）、`make-bgm.mjs`（三层合成床，不下载任何素材）

## 关键技术点

**一、灯箱是亮的，不是暗的。** 第一版按"焦糖黑底 + 暖黄光"画，深墨字压在深棕上完全没有对比，一屏糊。反过来——奶油琥珀底 + 深墨字 + 四角压暗——立刻成立。判断顺序必须是先定"这东西是亮的还是暗的"，再调色；反过来会一直在配色里打转。

**二、记号笔靠首尾重叠，粉笔靠留 gap。** 同一套"笔画"代码，v4 和 v5 的参数是反的：粉笔段与段之间空 2–4px 才断续，记号笔必须重叠 38% 才连续。笔身三段——洇（线宽 ×1.28、alpha 0.15）、笔身（短段步进 0.62、长度 13–21px）、积墨（起收笔各一个半径 0.56w 的实心圆）。速度用固定相位正弦，只抖线宽不抖位置，所以同一条线重画两次逐像素相同。

**三、手写字要加描边才像"摊主写的"。** 纯 `fillText` 用楷体是"书法"；叠一层 `strokeText`（线宽 = 字号 × 0.018）之后才是"粗头记号笔"。字逐个推进，每个字从上一字的位置起笔，所以"写"在时间上有先后。

**四、灯箱上的纸必须比板暗。** 纸挡光。第一版用 `#DCC49A` 压在中段板色 `#E9C892` 上，明度几乎一样，四张通知单糊成四块"没加载出来的占位图"，反倒是胶带最显眼。改成 `#C9A468`（更深）+ 上沿深边（贴住板面）+ 下沿 5px 亮边（光从纸缝漏出来），立刻是"贴着纸的灯箱"。推广成一句：**在这个介质里，所有附着物都比板面暗、且下缘亮；画成比板亮的，读者会当成光源。**

**五、蒸汽是三层同位叠加的锥形，不是线。** 一代等宽曲线描线 → 几根白面条；二代锥形 + 单层渐变 → 左右两条硬边，读成竖直光柱；三代锥形 + 三层同位叠加（宽度比 2.10 / 1.42 / 1.00，权重 0.15 / 0.32 / 1.00）→ 边界自己化开。**硬边靠宽度差消，不靠 blur**：shadowBlur 一帧就是几十毫秒，1800 帧付不起。另一个细节：渐变第一档必须从 alpha 0 起，否则轮廓底边那条水平线会被点亮，像贴了一块白塑料片。

**六、实物剪影的身份靠内容物，不靠轮廓。** 纸袋画了两版都被读成"一次性纸杯"——第一版错在袋口画了宽翻边（那是杯唇），第二版错在袋底宽给了 0.44（那是圆锥）。真正的修法是两件事一起：袋底宽 0.82（几乎是方的）+ 按 z 序画三层（后片高一点 → 暗口 → 袋里的栗子 → 前片）。**袋里有东西，就不可能被读成杯子。** 手同理：等长、等角、等粗的四根胶囊就是手套，要打破均匀——每根指自己长度与旋转、近端粗远端细、指根压在掌上。

**七、断言要测产物，不要测估算。** 配音那侧原本测"字数 / 总时长落在 3.4–4.6 字/秒"，实测下来这条既拦不住真问题（稿子超长 20%）又会误伤正常稿子（短句多、停顿多时字数密度天生偏低）。改成读对齐表：每句的语音时长必须放得进自己的镜头、语音总长不超过片长 90%、对齐表里的文本必须等于分镜里的文本（防"改了稿没重新合成"）。

## 已知缺陷

复用之前先看这几条，前三条会实际阻碍迁移：

| 缺陷 | 位置 | 说明 |
|---|---|---|
| **透射感不物理正确** | `drawPanel` + 所有文字 | 真实背光板上深色墨迹会切断透射光、形成硬边剪影；canvas 只有 alpha 混合，墨只是把底色压深。近景大字侧看会觉得"字浮在板上而不是长在板里" |
| **纸张是平面塑料片** | `paperStrip` | 没有纤维、没有厚度、没有重力卷边。旋转超过 ±0.05rad 时四条边仍是直线，靠近看读成贴图 |
| **手是剪影** | `hand` | 没有指节高光、没有指甲、没有掌纹。能读成"手"，但仍是一块深色几何体。要更好只有两条路：实拍素材，或真 3D |
| 蒸汽是锥形不是流体 | `steam` | 没有翻滚。全屏看是热气，拉近看是发光柱 |
| 栗子是一排均匀椭圆 | `bag` | 位置按固定表排布，略显装饰性，不像随手炒的一堆 |
| 纸袋没有褶皱 | `bag` | 只有两条侧折 + 中缝。真纸袋在被抓过之后会有不规则的塌陷 |
| 强调色预算是人工记账 | `AREA` | 靠渲染时累加填充面积，圆形按包围盒算，比实际大；断言卡 3% 是留了五倍余量 |
| 配乐没有音效层 | `make-bgm.mjs` | 合成床只有和弦 / 拨弦 / 空气三层。贴纸条、灯管启辉这些动作没有声音，只有 2% 的整片亮度脉冲当"视觉落点音" |
| 文档曾长期漂移 | `shots.json` 的 `visual` | 画面描述一度还写着「27℃」「两缕蒸汽」这类改版前的话——断言只检查"美术方向被镜头引用"，不检查描述是否属实。后来改成从渲染器导出实绘文字再回写 |

## 什么场合用

- 题材本身有**街头、现场、小生意**的味道：摊、店、作坊、当季的货。
- 要表达**"这个东西是热的 / 新鲜的 / 刚出锅的"**——背光板天然带温度，冷光和它正好相反。
- **观众是同行、熟人、街坊**，语气需要"说话"而不是"播报"。记号笔的手抖是资产，不是瑕疵。
- 画面里需要**贴、挂、标记**这类动作：价签、通知、便利贴、便当单。贴纸自带"临时/现场"的语义。
- 60 秒以内、以字幕和旁白承载信息、画面只做氛围与举证。

## 什么场合别用

- **要表达精确与专业。** 手写的数字天然不精确，画"增长 37%"会显得不可信。要数据去用 02 的制图台或 03 的示波器。
- **要展示成品与精致。** 记号笔是糙的、贴纸是歪的、纸边是撕的。适合"做事的过程"，不适合"做完的东西"。
- **高端或冷静的品牌。** 这套介质的全部力量来自"暖"和"近"，冷调品牌用它会显得土。
- **需要多元素并置对比。** 同时摆六个方块会被贴纸的纸质拖成一团。并置请用 02。
- **横屏或宽画幅。** 版面是按 9:16 排的：内容区 x 72–1008、标题带 240–700、主体带 700–1450、页脚 1520。改 16:9 是重排版面，不是改常量。
- **需要实拍质感的特写。** 手、纸袋、热气这三样在近景会穿帮（见缺陷前三条）。

## 换个题材怎么改

这套骨架的核心不是"灯箱"，是**"光从背后透过来，一切都贴在光前面"**这个关系。迁移时保的是这个关系，换的是贴在板上的东西：

1. **先定板子上"贴什么"。** 这一版贴的是价签、福利通知、卡券、时令清单——都是"现场手写、随手贴"的东西。换成别的题材，可以是排班表、菜单、快递单、检修单、招生简章。判断标准只有一条：**它是不是一张"被人随手贴在墙上"的纸。** 不是的话，这套介质就不合适。
2. **把"写 / 划 / 贴"三个动词分配到镜头上。** 这一版的动作序列是：写数字（第 1 镜）→ 贴价签（第 2 镜）→ 划掉（第 4 镜）→ 贴满（第 5 镜）→ 圈住（第 6、9 镜）。换题材时先排这三个动词的次序，再填内容；只填内容不排动作，就会变成"十张海报轮播"。
3. **改板面色温，但保住"上下亮、中间沉"。** 冷题材可以把 `#FFF7E2` 换成冷白、把 `#E9C892` 换成灰蓝，但纵向五档渐变和四角压暗必须留着——那是"板后有灯管"的唯一证据，去掉就变成一张纯色背景。
4. **重写字号阶梯，只留七档。** 这一版的七档是按"信息层级"定的（标题 / 主张 / 大字 / 中字 / 正文 / 小字 / 批注），不是按需要随意加的。新题材照这个层级重排七档，不要临时插值——插到第十档，画面就没有主次了。
5. **保住三道断言。** 强调色面积 ≤3%、同一时刻两次渲染必须同帧、源码里不许出现 `Math.random` / `shadowBlur` / `destination-out` / 混合模式 / `ctx.filter`。前两条保"红不泛滥"和"可复现"，第三条保"边缘靠 alpha 分层而不是引擎特效"，这直接决定它在 1800 帧上的成本。

不要改的是：**纵向渐变的五档结构、记号笔的三段笔身、逐字书写、纸比板暗**。这四条决定了它"像灯箱"而不是"像一张暖色海报"。

## 风格引导块

换题材时不用重读上面全部，把这段整块复制走即可——喂给 AI 是风格提示词，落成代码是常量表。

```
视觉：街头小吃的背光亚克力灯箱板。板子自己是光源，字和纸都贴在光前面。
板面：纵向五档渐变 #FFF7E2 → #F8E4BA → #E9C892 → #F8E4BA → #FFF7E2（上下亮、中间沉），
      四角径向压暗 #6B4620 到 0.78；灯管色 #FFD98A、芯 #FFF7E4。
墨色 #2A1B10（粗记号笔）；纸正面 #FBF2E2、背面 #C9A468（纸比板暗，下缘留 5px 亮边）；
胶带 #F0D68C 58×27px 斜贴；蒸汽 #FFFDF5；辣椒红 #C8452B 只做批注，全帧面积 ≤3%。
笔迹：一条线由短段首尾重叠 38% 拼成（不是虚线，是实线但每段都换手）；
      外加一层更宽的淡洇（1.28 倍线宽、alpha 0.15）和起收笔各一个积墨圆。
字：楷体（KaiTi / Kaiti SC），字号七档 150 / 96 / 72 / 56 / 44 / 34 / 27px，
    逐字写出；fillText 之后再 strokeText 一层，线宽 = 字号 × 0.018，才是记号笔。
纸：贴上去要回弹（easeOutBack 1.9），投影用三层偏移圆角矩形，不要 blur。
动作：写 → 划 → 贴。划是红线压在字上，贴是纸片带胶带斜着贴住。
安全区：x 72–1008px，y 210–1600px（底部 18% 留给平台 UI）。
不要：shadowBlur、发光光晕、圆角卡片、渐变按钮、无衬线细体、任何"科技感"网格。
```

配套的五条硬约束：

- 纸必须比板**暗**，下缘留亮边。画成比板亮，读者会把纸当成光源。
- 蒸汽硬边只能靠"三层不同宽度叠加"消，**不能用 blur**——一帧几十毫秒，1800 帧付不起。
- 记号笔的段与段必须**重叠**（约 38%），粉笔才留 gap。参数反了就没有笔迹感。
- 所有随机量走固定种子，同一时刻两次渲染必须逐像素相同；`Math.random` 一出现就没法比对。
- 实物剪影的身份靠**内容物**（袋里的栗子、杯里的水），不要指望轮廓。

---

**和 01–04 的关系：** 不是第五次进化，是第五次独立选择。写这支片时"严谨"、"对比"、"推导"都不对——要的是**"热乎"**，所以选了"光从背后透过来"的介质。前四版换的是表面（发光屏 / 纸 / 玻璃 / 粉笔灰），这一版换的是**光的方向**：不是光照在表面上，是表面自己发光。
