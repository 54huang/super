# 案例 02 · 制图台

**状态：现役。** 实现 `renderer/src/shot-renderer.js`，参数 `specs/style-tokens.json`，页面 `renderer/index.html`，**七镜全片 S01–S07（30.000 秒）**。

## 一句话

把 C++ 代码当作工程图纸画在暖白纸上，用墨线制图语汇排版，朱红批注是唯一"人"的痕迹。七镜串成一条完整的 30 秒——从否定常识到盖章结论。

## 视觉构成

| 项 | 值 |
|---|---|
| 纸底 | `#F4EFE3` → `#E3D9C4` 纵向 |
| 墨 | `#1B1A17`／次级 `#4A463C` |
| 制图蓝 | `#2B4A6F` |
| 朱红 | `#BE3A2B`（**面积上限 3%**） |
| 标记黄 | `#D9A521` |
| 细格 | 36px，alpha 0.045，1px |
| 粗格 | 180px，alpha 0.10，1.4px |
| 线宽层级 | 主框 2.5 / 内框 1 / 辅助线 1 / 尺寸线 1.2 / 批注 3 |
| 字号体系 | 52 / 25 / 20 / 17 / 13 / 11，六级以内 |
| 字体分工 | 中文标题用宋体，代码与数值用等宽，其余无衬线 |
| 层次 | 7 层，第 5 层是批注层 |

## 实现入口

- `renderer/src/shot-renderer.js` — 全部绘制逻辑
- `specs/style-tokens.json` — 色板、网格、线宽、字号、层序、种子
- `tests/tokens.test.mjs` — 断言「令牌里每个色值都必须真的出现在源码里」，防文档与实现漂移

## 关键技术点

**对比来自错位，不是来自配色。** 代码是冷的、精确的、无机的；纸是暖的、有纤维的、会脏的。把前者印在后者上，冲突本身就产生注意力。单纯把背景换成米色不会有这个效果——必须是"冷内容"落在"暖载体"上。

**朱红只出现在批注，面积不超过 3%。** 这是纪律，写进了 `constraints.accentMaxArea`。批注一多，画面就从"图纸"变成"涂鸦"。

**线宽必须有层级。** 主框 2.5、内框 1、辅助线 1，全部一样粗会糊成一片。这条写进了 strokes 的 note 字段。

**图注编号提供档案感。** `CODE-01`、`FIG.S03` 这类编号不承载信息，但让画面像"从某个档案里抽出来的一页"，而不是"设计出来的海报"。

## 已知缺陷

| 缺陷 | 说明 |
|---|---|
| 混剪对齐极脆弱 | 纸色、网格相位、线宽三者必须和 AI 段严格对齐，差一点就露出接缝。这是整套方法最容易翻车的地方 |
| 单镜内表达不了动态先后 | 纸面是印好的，一帧之内说不出"A 先于 B"。时序只能靠**镜头推进**（S01→S07）和打字机/描线的时间差来暗示，不能在单帧里并置 |
| 表达不了对比 | 能画"RAII 会析构"，画不出"不 RAII 会怎样"。并排放两张纸又占满画面 |
| 依赖系统字体 | 宋体（`Songti SC` / `SimSun`）与雅黑在 Linux、无头浏览器里常缺失，落到通用 serif 后字宽变化，逐字绘制的标题会溢出 |
| 等宽栈没有中文兜底 | `monospace` 通用族在浏览器里能隐式 fallback 到中文字体，在 Skia（Node 端渲染）里不能，直接画成豆腐块。见下 |

最后两条是真坑。`tracked()` 用 `measureText` 累加宽度做字距，字体一换整行宽度就变，排版跟着崩；而等宽栈里的中文更隐蔽——浏览器看着一切正常，换到 Node 端出片才发现「调用来源」变成了四个方块。

**已采用的解法**：字体文件固定在盘上（`D:\Tools\fonts` 的思源宋体 400/700），栈里显式写出中文字体名，让两端都命中同一份文件：

```
F_DISPLAY  "Songti SC","Source Han Serif CN","SimSun","Noto Serif SC",serif
F_MONO     ui-monospace,Consolas,"Courier New","Source Han Serif CN","Songti SC","SimSun",monospace
```

顺序有意义：装了思源宋体就用它（有真 700 字重），没装自动落到 SimSun，浏览器行为不变。

## 什么场合用

- 内容本身是**精确符号系统**：代码、公式、协议、乐谱、化学式、法律条文。
- 需要表达**严谨、可追溯、有人核对过**的语义。
- 观众会**暂停看细节**——纸面的信息密度经得起看。
- 竖屏 9:16 知识类口播，暖白在信息流里比深色更容易被"停下来"。

## 什么场合别用

- **需要表达动态过程**。纸上的东西是印好的，再动也是"翻页"。构造与析构的先后关系，纸面画不出来（这就是 03 出现的原因）。
- **需要表达对比**。能画"A 是这样"，画不出"B 不是这样"——除非并排放两张纸，但那样又占满画面。
- **AI 生成镜头混剪**。纸面的纸色、网格相位、线宽必须和 AI 段严格对齐，错一点就露馅。这是这套方法最脆弱的地方。
- **娱乐、潮流、快节奏内容**。制图语汇自带"严肃"信号，用在轻松题材上会显得用力。

## 换个题材怎么改

这套方法的可迁移性很高，因为它的骨架不依赖具体内容。改四个地方就够：

1. **纸色决定温度。** 暖白（默认）适合知识/技术；冷白偏医疗与实验室；牛皮纸偏档案与年代感；淡蓝晒图纸（cyanotype）偏建筑与工业。**只改纸色不改网格，质感立刻变。**
2. **冷内容换成你领域的精确符号。** 代码可以换成 SQL、正则、电路图符号、五线谱、元素周期表片段。判断标准：这个符号系统必须有"一个字符错了整个意思就错"的属性。
3. **批注是唯一该有观点的地方。** 朱红内容要用**人写字的语气**：「close 谁调？」而不是「注意资源释放」。前者是疑问，后者是说明书。这一条决定了画面像"档案"还是像"教材"。
4. **图注编号改前缀。** `CODE-` 改 `FIG.`、`EXH.`、`APP.`，跟着题材走。

不要改的是：**线宽层级和 3% 强调色上限**。这两个是让它不糊、不脏的底线，改了就不是这套东西了。

## 风格引导块

换题材时不用重读上面全部，把这段整块复制走即可——喂给 AI 是风格约束，落成代码是常量表。

```
视觉：工程制图台，暖白纸面。底色 #F4EFE3→#E3D9C4 竖向渐变；
细格 36px 透明度 0.045，粗格 180px 透明度 0.10，墨色 #1B1A17。
线条：主笔 2.5px，辅助结构线 1px，引线 1px 虚线，边框 3px。
强调：朱红 #BE3A2B 只用于批注、否定、盖章，面积不超过画面 3%。
字体：中文标题宋体 600 字重，代码与数值用等宽；字号层级 52/25/20/17/13/11。
语汇：四角定位标记、尺寸线、图号 FIG.、折角、纸屑。不要装饰性插画，
不要光晕，不要科技蓝。质感来自纸与墨，不来自光。
```

配套的三条硬约束（抄参数时容易漏）：

- 朱红面积一旦超过 3%，从"批注"变成"贴纸"，语义就废了。
- 字号不超过 6 级，超过就没有层级感。
- 等宽字体栈必须显式写出中文字体名，否则 Skia 里中文会变豆腐块（浏览器看不出这个问题）。
