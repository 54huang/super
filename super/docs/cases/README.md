# 案例库

这里是做过的视觉方向，一个案例一张卡。

**不是产品展示，是参考存储。** 将来想复用某种质感、某套动效、某种论证方式，从这里查；查到了就知道该动哪个文件、调哪几个参数、避开哪些坑。

样本之间不需要风格协调——它们是并列的参考，不是同一套模板的变体。

## 案例卡规范

每张卡固定八节，缺一节 `npm test` 会红：

| 节 | 回答什么 |
|---|---|
| 一句话 | 这个东西是什么。不许用形容词堆砌 |
| 视觉构成 | 可量化的参数：色值、线宽、网格间距、字号、缓动 |
| 实现入口 | 文件、导出名、可调参数在哪一行附近 |
| 关键技术点 | 要复现必须知道的事，不写就做不出来 |
| **已知缺陷** | 这一版哪里会翻车。只记优点的话，复用的人会踩同一个坑 |
| 什么场合用 | 适用判断，不是优点列表 |
| 什么场合别用 | 明确的不适用清单，要具体 |
| 换个题材怎么改 | 迁移方法——**这张卡最有用的部分** |

前七节是档案，第八节是方法。只抄前七节，下次还得重想一遍。

「已知缺陷」不是自我检讨，是**风险清单**。复用一个方案之前，先知道它会在哪裂开。

## 现役风格另带一节：风格引导块

02–09 末尾还有一节 `## 风格引导块`——一段**能整段复制**的约束文本（01 没有，它是弃用留档）：

- 喂给 AI，它就是风格提示词；
- 落成代码，它就是常量表；
- 换题材时不用重读整张卡，抄走这一段就够。

测试会检查它确实是代码块、含具体色值与尺寸、长度够撑一次迁移。否则「选中心仪风格」就只是看个热闹——看得见，拿不走。

## 九个案例

| # | 案例 | 介质 | 状态 | 一句话 |
|---|---|---|---|---|
| 01 | 深空蓝 | 深色渐变 + 线框几何 | 弃用留档 | 第一版，技术正确、视觉平庸 |
| 02 | 制图台 | 暖白纸 + 墨线 + 朱红 | 现役 | 冷内容写在暖纸上，批注是人的动作 |
| 03 | 示波器 | 黑玻璃 + 荧光波形 | 现役 | 横轴是时间，两条线的落差就是论证 |
| 04 | 黑板粉笔 | 墨绿板面 + 粉笔灰 + 木框 | 现役 | 每一笔有先后，划掉和写下同等重要 |
| 05 | 暖摊灯箱 | 背光亚克力板 + 记号笔 + 贴纸条 | 现役 | 板子自己是光源，一切都贴在光前面 |
| 06 | 年度计划表 | 打印的 A4 表 + 圆珠笔 + 印泥 | 现役 | 同一张纸被一年一年地填，痕迹不会消失 |
| 07 | 丝网印刷 | 两种油墨 + 5px 错版 | 实验·单帧 | 同一内容印两遍，两遍没对准 |
| 08 | 电子墨水屏 | 无背光灰阶 + 局部刷新残影 | 实验·单帧 | 改过的东西不会立刻走，屏幕记得上一屏 |
| 09 | 金属铭牌 | 拉丝铝 + 凹刻 + 铆钉 | 实验·单帧 | 刻上去的东西，改不了 |

**07–09 只有单帧，没有成片。** 它们验证的是同一件事：这个介质能不能**一眼认出来**。认出来了才有资格进分镜，认不出来就到此为止。所以这三张卡的「已知缺陷」比前六张更硬——里面全是验证时真撞上的墙，不是预想的。

三张的强弱是 07 ＞ 08 ＞ 09。09 最弱，理由写在它自己的缺陷表前两条：**凹刻在手机尺寸上会退化成普通深色字**，而且它只有终态、撑不了一支片。

## 为什么留着被推翻的 01

它记录了一个**具体的错误**：把「科技感」理解成「青色发光 + 线框立方体」。

这个错误会反复出现，因为 AI 视频的训练数据里全是这个——写「科技感」「未来感」，模型就给你青色霓虹。留着 01，下次想往那个方向走时，先看一眼它的下场。

## 九张卡的关系

不是从 01 到 09 的进化，是九次独立的选择：

- 01 想表达「技术」，选了科技风的默认答案 → 失败
- 02 想表达「严谨」，选了工程制图 → 成立，但只能"陈述"
- 03 想表达「配对关系」，选了仪器 → 成立，能"对比"
- 04 想表达「推导过程」，选了板书 → 成立，唯一能"改"的一版
- 05 想表达「热乎」，选了背光灯箱 → 成立，唯一"表面自己发光"的一版
- 06 想表达「周期与累积」，选了年度计划表 → 成立，唯一能"填满又划掉、痕迹留在上面"的一版
- 07 想表达「复制与失真」，选了两版套印 → 成立，唯一画面里同时有两份内容的一版
- 08 想表达「信息滞后」，选了电子墨水屏 → 成立，唯一画面里同时有两个时刻的一版
- 09 想表达「不可撤销」，选了金属铭牌 → 部分成立，只能撑一个结论

前五版换的都是**介质**：发光屏 → 纸面 → 玻璃 → 粉笔灰 → 从背后透光。五版都在回答"光落在什么表面上"。

06 换的是**动作**：不是看什么，是同一个东西被一年一年地处理。由此推出来的一切（十二行必须一条不少、打印动画只能归第一镜、旧字要留成 alpha 0.42、圈和划用两种红）都是这一条的结果，不是配色偏好。

07–09 换的是**结构**，不是表面也不是动作：

- **07 换的是"版本"**——画面里同时存在两份同一内容，而它们没对齐。它第一次让"复制"本身成为题材。
- **08 换的是"时刻"**——旧内容不走。前七版的时间都是"正在发生"，只有它是"已经发生而还没消失"。
- **09 换的是"可改性"**——前八版都还能改（擦、刷、重写），它不能。代价是它撑不了一支片。

05 和 06 差得最远，也最能说明一件事：**"同一张纸"这种立论，只有在运动（推镜、逐字写、痕迹累加）里才成立。** 06 原本是全片零镜头运动的，加推镜之后才暴露出第一镜写的字在第三镜就消失了——静态时看不出来，动起来藏不住。

07–09 三条里有一条是失败的：**09 的单帧做得出来，片子做不出来。** 留它是因为失败的原因值得记——凹刻的明暗差在手机尺寸上只剩 3px，这是个跟画法无关的物理限制。案例库如果只收成立的东西，复用的人就得自己再撞一次。

每张卡的「什么场合用」写的就是这个判断，选之前先读那一节。
