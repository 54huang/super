# 案例 06 · 年度计划表

**状态：现役。** 十镜 R01–R10，60 秒竖屏，为一条 B2B 短片做的。实现不在本仓库——它在交付工程 `aigc_video_rhythm` 里，主文件 `paper-renderer.js`（约 950 行）。这张卡记录的是画法与取舍，不是代码。

## 一句话

喷墨打印的 A4 年度计划表压在深墨绿桌面上，用圆珠笔、复写纸和印泥往上填：**同一张纸，被一年一年地填。**

## 视觉构成

| 项 | 值 |
|---|---|
| 桌面 | `#1E2622`，木纹短划痕 150 条（长度 40–190px、角度 −0.35±0.06rad、alpha 0.020–0.044），中心偏上径向提亮 0.30、边缘压暗 0.34 |
| 纸 | 上下两档渐变 `#E4DAC2` → `#F6F1E3` →（44% 处）`#FFFDF6` → `#F6F1E3` → `#E4DAC2`，模拟中缝弓起 |
| 纸边 | 每条边切 24 段，各自抖 ±1.5px。四边都不是直线，`fillRect` 画出来会像显示器边框 |
| 纸纤维 | 220 根短划（6–32px），alpha 0.020–0.050 |
| 表格线 | `#B4BAAA`，1.6px；淡季行压到 `#CBD0BF` / alpha 0.28 |
| 栏名 | `#6B6F63`，宋体（`Source Han Serif CN` / `Songti SC` / `SimSun`） |
| 针打墨 | `#2A2C3E`，等宽 + 0.6px 右下重影，重影 alpha 0.30 |
| 复写墨（手填） | `#3C3F7A` — 染料微胶囊被压破渗出来，天生偏蓝紫。全片只有"手填"用它 |
| 圆珠笔红 | `#BE3A2A` — 圈、划、括 |
| 印泥红 | `#B0342B` — 只盖一次 |
| 字号阶梯 | 64 / 52 / 40 / 34 / 30 / 26 / 22（七档） |
| 版式 | 纸 x 76–1004、y 180–1720；左内边距 132、右内边距 948；十二行从 380 起、行距 86、行线在基线下 42 |
| 安全区 | x 72–1008，y 210–1574（底部 18% 让给平台 UI） |
| 取景 | 十镜 z 终值 1.06 / 1.16 / 1.40 / 1.42 / 1.10 / 1.22 / 1.22 / 1.24 / 1.12 / 1.20，上限 1.45 |
| 十镜时长 | 6 × 10 = 60 秒（第一版是 6+4+8+6×7，见「关键技术点」第八条） |
| 强调色预算 | 全帧红色（两种红合计）≤ 3%，按**屏幕**面积记账（乘 z²）；实测最高 S09 的 1.09% |
| 单帧成本 | 96ms（1800 帧 173 秒，含 PNG 编码） |

## 实现入口

- 主文件 `paper-renderer.js`：十镜脚本 + 十余种画法，导出 `window.Paper`
- 画法：`drawDesk`（桌面）/ `drawPaper` + `paperPath`（纸与纸边）/ `rule`（线）/ `labelText`（宋体栏名）/ `typeText`（针打重影）/ `handText`（楷体逐字）/ `pen`（圆珠笔）/ `ring` / `box` / `brace` / `stamp`（印泥）
- 骨架：`monthTable(c, {alpha, t, gray, dy})` —— `t` 是打印进度，只给第一镜传非 1 的值
- 痕迹：`peakMarks(c, o)` —— 第一镜之后每一镜都要重画的"旺季三行"
- 相机：每镜声明 `cam: {x0,y0,z0, x1,y1,z1, sub}`，`camAt(shot, p)` 用 smoothstep 插值；`paint()` 把 transform 包在 `shot.draw` 外面
- 记账器：`AREA.red`（屏幕面积）、`SHEET.months`（每画一行记一笔）——测试直接读渲染器自己的账，不做截图像素分析
- 引擎导出：`init` `select` `seek` `toggle` `onChange` `exportFrame` `exportSequence` `renderAt` `camAt`
- 配音与配乐也是算出来的：`tts-align.mjs`（逐句合成 + 按实测秒数摆位，塞不进直接报错退出）、`make-bgm.mjs`（现场合成，不采样）

## 关键技术点

**一、十二行是唯一的骨架，不是背景。** 整支片的立论是"同一张表被一年一年地填"，所以每一镜都必须完整画出 12 行、顺序 01→12，少一行观众就会觉得"换了一张纸"。这条写成了断言：渲染器每画一行往 `SHEET.months` 记一笔，测试数长度和顺序，**除第一镜外第 0 帧就必须完整**。加了推镜之后这条契约多了一层——行不光要"画"，还要"在画面里"，于是又加了一条：推到最紧时十二条行线必须全在画面内。

**二、打印动画只属于第一镜。** 第二镜一度带着打印进度（`t: seg(p, 0, 0.10)`），结果开头痛快地把表重新印了一遍——那不是"又看了一次表"，是"换了一张纸"。此后九镜一律 `t: 1`。**连续性不属于某个镜头，属于整支片**，任何"从头再来一遍"的动作都会把前面的信用清掉。

**三、纸不淡入。** 竖屏短片的第一帧同时是封面图，封面不能是一块半透明灰板。改成不透明落定：位移负责"落"（`dy: (1-drop) * -40`），打印进度负责"出现"，`alpha` 全程 1。**"出现"这个动作要有且只有一个来源**，两个来源叠加时，第一个 300ms 一定是糊的。

**四、三种字必须三种来路。** 针打（等宽 + 0.6px 重影）是机器敲的；栏名宋体一出现就是完整的（印上去的，不是写上去的）；楷体手填逐字写、起笔先淡后实、落点比基线低 0.9px。三种字如果都用 `fillText` 默认画，一眼就是"排版"，不是"被敲上去 / 被写上去"。

**五、两个红不能混。** 圆珠笔红 `#BE3A2A`（圈、划、括，圆珠笔在纸上不渗，只有线宽抖动）与印泥红 `#B0342B`（章，双层错位 + 双线框，只盖一次）。这是两种笔、两种意思。面积预算按**屏幕**面积算并乘 `z²`——同一笔在 1.4 倍下占的像素多一倍，按纸面记账会在缩得最紧的几秒悄悄破 3% 而账面正常。

**六、推镜是取景层的变换，不是纸面的变形。** 每镜只声明起点/终点取景和一个"主体矩形"，笔画代码一行不用改。三条硬约束：倍数 1–1.45、帧间连续（|Δz| ≤ 0.01）、只推不退（推到一半往回退，观众会看出"镜头在找东西"）。上限 1.45 不是审美决定的，是算出来的：竖屏 1920 高、行区只占 946，z=1.42 时可视 1352，**刚够装下整块行区**。想再紧，骨架就出画了。

**七、符号和文字分属两个坐标系，第一版就要定。** 页脚说明原本画在纸面 y=1570，离平台 UI 区（1574）只有 4px——零运动时是"能放就放"的侥幸，一加推镜就掉进 UI 区。改到屏幕坐标 `CAPTION_Y = 1510`（不跟着缩放）之后又撞了第二回：推镜把 12 月那行推到 1526/1531，正好压在这行字上，"12 月"和"一年三个高峰"叠成一团。最后是两头一起让——页脚下移、三镜取景中心下移——才空出来。**这类事故在 540px 的缩略图上比在 1080 原图上更明显**，所以出片后必须缩到手机尺寸再看一遍。

**八、改稿是为了时长，不是为了字数。** 第一版时间码是全片唯一的解：`6+4+8+6×7`，因为逐句量过秒数，只有第二镜塞得进 4 秒。第二版要加推镜，4 秒镜做"全景 → 特写"太赶，于是十镜统一 6 秒，代价是第三镜要减字（删一个「在」，5.50 → 5.46 秒）。**先量秒数再排时间码**，顺序反了要重排整份分镜和每镜内部的动画时间点。

## 已知缺陷

复用之前先看这几条，前三条会实际阻碍迁移：

| 缺陷 | 位置 | 说明 |
|---|---|---|
| **推镜没有景深** | `paint` 的 transform | 缩放是整层等比，纸边和字一起放大，没有虚化、没有视差。近景看是"放大了一张图"，不是"镜头凑近了"。canvas 2D 做景深要分图层多次绘制，成本不成比例；纸是平的，等比放大反而诚实 |
| **针式打印没有点阵** | `typeText` | 只有 `fillText` + 0.6px 重影。真针打的字由 9 针或 24 针的点阵拼成，横竖笔画有明显的锯齿阶梯。放大到特写时一眼能看出是"字体"，不是"打印" |
| **圆珠笔没有笔压** | `pen` | 只有线宽抖动（0.88–1.14 倍），没有真实笔压的墨量衰减。真圆珠笔在起笔处积墨、收笔处发白，这套没做 |
| 纸的弓起是渐变 | `drawPaper` | 纵向五档渐变冒充曲面，纸边仍是二维曲线。大角度俯看（取景再偏）会穿帮；当前 90° 正俯视是安全的 |
| 手写字体依赖系统楷体 | `F_HAND` | 栈里写了 `KaiTi` / `Kaiti SC` / `楷体` / `Source Han Serif CN`。**只在 Windows 上验证过**；换到没装楷体的机器会回落到宋体，手写气质会变成印刷体 |
| **第三、四镜月份号整列出画** | `S03`/`S04` 的 `cam` | 推到 1.40 时画面只有 771px 宽，而"09 月的圈"（x=190）和"节前两周的框"（x=636–948）相距 758px，装不下两个。行线还在（断言守着），但"这是几月"要靠第三镜开头 0.8 秒交代。想同时保住两者，上限只能到 1.15，那就不算特写了 |
| 第三镜旁白贴着窗口 | `specs/shots.json` | 5.46s 塞进 6s，余量 0.02s，TTS 用 1.01 倍速换来的（不可闻）。**全片唯一一句贴着窗口的**，改稿前先动别处 |
| 红色面积是人工记账 | `AREA.red` | `线长 × 线宽 × z²`，圆形按包围盒算，抗锯齿和 alpha 都不计。断言卡 3% 是留了安全边，不是精确测量 |
| **纸上的痕迹是每镜手抄的** | `peakMarks` | 第一镜写下的节名、第二镜圈的月，后面每一镜都要重新调一次函数画上去。这不是状态机，是补丁——漏调一处，那一行就会"自己消失"。真正的做法是把纸上的痕迹做成显式状态（画过就一直在），这一版没做 |
| 全片硬切，无转场 | 剪辑 | 第三→四、第七→八镜是匹配剪辑（取景几乎相同，切点几乎无感），其余切点靠取景差异拉开。没有淡入淡出、没有叠化 |

## 什么场合用

- 题材本身有**周期、节奏、年度安排**的味道：年度计划、排期、账期、排班、季节生意、农时、学期。
- 要表达**"同一件事被反复处理"**——填、划、圈、改，痕迹累加在同一张纸上。这是这套介质唯一不可替代的能力。
- **观众是做事的人**，语气是"对账"而不是"播报"。手写的歪、圈得不圆、字压着字，都是资产。
- 需要**"这张表有历史"**的暗示：复写墨偏蓝紫、淡季行被压灰、上一版写的字比这一版淡。
- 60 秒以内、信息靠字幕与旁白、画面只做举证。

## 什么场合别用

- **要卖东西。** 这张表里没有任何产品。客户看完不知道自己能买什么——它是给同行看的复盘，不是落地页。
- **要情绪高潮。** 纸和笔天生是平的。十二行反复出现，力量来自累积而不是爆发。要燃、要暖、要热闹，去用 05 的灯箱。
- **短于 30 秒。** 十二行需要时间被读完。30 秒内它只是一张花纸，观众记不住"同一张表"这个前提。
- **要精确数据。** 手写的数字天然不精确，画"增长 37%"不可信，画"这里多、这里少"才对。要精确图表去用 02 的制图台。
- **需要对比两条序列。** 这张表只有一条时间轴。要"正确 / 错误"的落差，去用 03 的示波器。
- **横屏或宽画幅。** 版面是按 9:16 排的：纸 x 76–1004、行区 y 380–1368、选项带 y 1400–1480、页脚 y 1510。改成 16:9 是重排版面，不是改常量。
- **需要特写看清小字。** 推到 1.4 倍就是这套骨架的物理极限（见缺陷表第三条），再近十二行就留不住了。

## 换个题材怎么改

这套骨架的核心不是"年度表"，是**"一张有固定格子的纸，被一格一格地填，痕迹留在上面"**。迁移时保的是这个关系，换的是格子里的内容：

1. **先定"格子"是什么，以及它为什么不能变。** 这一版是十二个月，因为"一年"是全片的时间单位，而十二行是全片唯一的骨架。换成学期就是 18 周、换成产线就是 7 个工位、换成排班就是 7 天。判断标准只有一条：**这个格子数，观众看一眼就知道是"一整年 / 一整轮"吗。** 不是的话，这套介质撑不起累积感。
2. **把"填 / 圈 / 划 / 盖章"四个动词分配到镜头上，再填内容。** 这一版：打印（第 1 镜）→ 圈出高峰（第 2 镜）→ 挤进框（第 3、4 镜）→ 填淡季（第 5、6 镜）→ 二选一（第 7、8 镜）→ 汇总（第 9 镜）→ 落章（第 10 镜）。先排动词次序，再往里填字；只填内容不排动作，就会变成十张表格轮播。
3. **重排取景，但守住"行线全在画面内"。** 十镜的 z 终值不是均匀分布的：需要读小字的两镜推到 1.40/1.42，陈述性质的四镜只到 1.06–1.12，切回宽景的那一镜（第 5 镜）是全片唯一一次从 1.42 拉回 1.00。**推镜的幅度由"这一镜要不要读字"决定，不由节奏感决定。** 换题材时按同样的逻辑重排，然后跑一遍行线断言，红了就说明推过头了。
4. **重定"哪些痕迹必须一直留着"。** 这一版是旺季三行的圈与节名、上一镜写的旧字（alpha 0.42 表示"昨天写的"）、被压灰的淡季行。换题材时先列这张清单——**清单上的东西每一镜都要重画一遍**，漏一个，那一格就会凭空消失，而零运动时你还看不出来。
5. **保住四道断言。** 十二行每镜画满且顺序不乱、除打印镜外第 0 帧就完整、红色（按屏幕面积）≤3%、同一时刻两次渲染必须同帧（所有随机量走固定种子）。前两条保"同一张纸"，第三条保"红不泛滥"，第四条保"可复现"——第四条尤其要紧，`Math.random` 一出现，逐帧导出的整条片都会抖。

不要改的是：**十二行固定、纸边抖动、三种字三种来路、两个红分开、取景上限 1.45**。这五条决定了它"像一张真的表"而不是"像一张表格的插画"。


配套的五条硬约束：

- **十二行一镜都不能少，除打印镜外第 0 帧就必须齐。** 少一行 = 换了一张纸，前面所有镜头作废。
- **打印动作只归第一镜。** 任何一镜"从头再印一遍"都在否定连续性。
- **纸不淡入。** 竖屏第一帧同时是封面，`alpha` 全程 1，用位移和打印进度表达"出现"。
- **两个红不能混**，圈划用圆珠笔、盖章用印泥；面积按屏幕算，不是按纸面算。
- 所有随机量走固定种子，同一时刻两次渲染必须逐像素相同。

---

**和 01–05 的关系：** 不是第六次进化，是第六次独立选择。01–05 换的全是"光落在什么表面上"（发光屏 / 纸 / 玻璃 / 粉笔灰 / 自发光板），这一版换的是**动作**——不是"看什么"，是"同一个东西被一年一年地处理"。前三版都能说"这个对象是什么样"，第四版能说"推导过程"，这一版唯一能做的是**累积**：痕迹留在纸上，填过的不会消失，划掉的还在底下。
