## 为什么是节点

它的用法是**发散**而不是收敛：给一个想法，用 21 套不同生成器各出一版电影级提示词，然后你挑最好的那条再改。对"卡在第一步、不知道该怎么写"的状态特别有效 —— 先有 5 个候选，再谈优化。

## 它能给你什么

1. **21 套生成器 = 21 种镜头思路**：同一题材能得到完全不同的镜头方案，用来破除思维定式。
2. **电影级措辞**：它输出的提示词天然带景别、机位、光线，不用你再补。
3. **多模型适配**：一份想法可以分别按 Sora/Kling/Veo/Seedance 的语法出，直接对比哪个平台更适合这个题材。
4. **改写的起点**：AI 出的版本通常"正确但平庸"，拿它当草稿改，比白纸快。

## 抖音 9:16 用法

- 一次生成 4-5 版 → 挑画面感最强的一版 → 手动加竖屏约束与单镜时长。
- 它的输出偏"电影镜头"，竖屏要**把景别整体推近一档**、镜头数量翻倍。
- 用不同生成器分别出"钩子镜"和"卖点镜"，风格差异反而能形成节奏对比。

## 取用路径

1. 根 README 看生成器清单 → 选 3-4 个。
2. 输入同一个想法 → 对比输出。
3. 选一版 → 套 `00_起点/可直接粘贴模板.md` 的六段式精修。

## 注意

别指望第一版就能用 —— 它的价值是**给起点**，不是给成品。
