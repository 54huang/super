## 为什么是节点

绝大多数提示词库解决"这一条怎么写"，这个解决**"每次都怎么写"**。把重复决策压成表格规则：选题什么标准、脚本几段、镜头几张、提示词哪几段、验收看什么。产能上不去的时候，问题通常不在提示词，在这里。

## 它能给你什么

1. **SOP 表格**：把流程变成"打勾清单"，新人也能按表产出。
2. **规则化验收**：什么算合格、什么必须重做 —— 减少"看感觉"的返工。
3. **模板库**：常用的几套结构（口播、产品、剧情、知识），而不是从零写。
4. **提示词与流程绑定**：哪一步该用哪种提示词，写在同一张表里，避免"写提示词时忘了目的"。

## 抖音 9:16 用法

- 直接改成自己的"日更表"：一天一条，每条走同一张表。
- 竖屏要额外加三条规则进表：首帧必须有主体、每 8 秒必须有变化、字幕不越底部 15%。
- 做矩阵号（多账号同题材）时，这张表就是标准化工具。

## 取用路径

1. 根 README 看表格结构。
2. 抄成自己的 Notion/飞书表格（不必用它的工具）。
3. 跑 5 条片子后回来改表 —— 表是迭代出来的，不是一次写好的。
