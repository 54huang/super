## 为什么是节点

抖音带货视频的痛点不是"画面好看"，而是**前 3 秒抓不住人 + 卖点没讲清 + 字幕花字不规范**。这个仓把 13 个环节都做成了技能：3 秒钩子、爆款翻拍、卖点分镜、edge-tts 配音、字幕花字、ffmpeg 本地合成、多平台导出（抖音/TikTok Shop/视频号/小红书/淘宝主图/Amazon）。而且**不需要 API key**，本地就能跑。

## 它能给你什么

1. **钩子模板**：3 秒钩子的结构（疑问/反差/结果前置），换品类直接套。
2. **卖点分镜法**：把产品卖点排成镜头顺序，而不是罗列参数。
3. **花字与字幕规范**：抖音的花字样式、字号、出现时机 —— 这块多数人靠感觉，它有规则。
4. **`tools/` 的 ffmpeg 合成**：图片 + 配音 + 字幕 + BGM → 成片，全本地，成本接近零。
5. **多平台导出参数**：同一素材出多个平台的规格，不用各平台重做。

## 抖音 9:16 用法

这是它的原生场景，直接按技能顺序走：
```
商品图 → 3秒钩子 → 卖点分镜 → 逐镜提示词 → 出图/出片 → edge-tts 配音 → 花字 → ffmpeg 合成 → 导出
```
- 钩子镜单独一条提示词，**不要和卖点镜混**。
- 竖屏产品镜头以"手持 + 桌面俯拍 + 特写"为主，别用全景。
- 字幕位置：底部 20% 以上，避开抖音的文案与按钮区。

## 取用路径

2. `skills/` 取钩子与卖点分镜两个先跑通。
