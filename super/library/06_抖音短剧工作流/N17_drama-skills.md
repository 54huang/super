## 为什么是节点

短剧/漫剧这条链路上**最完整的开源工作流**：一个点子或一部原著 → 分集剧本 → 角色资产 → 分镜 storyboard → 图片/视频提示词 → 审查。而且它是**按环节拆成独立技能**的，你可以只取其中一环（比如只要"分镜"那一个），不必全装。

## 它能给你什么

1. **环节切分方式**：剧本、角色资产、分镜、提示词、审查 —— 这五段划分本身就是做系列内容的骨架。
2. **角色资产的概念**：把人物登记成"资产"（外观、服装、性格、常用角度），后续所有镜头引用资产而不是重新描述 —— 这是长篇一致性的唯一解法。
3. **`evaluations/`**：它有自己的质量门，可以借来当"这条片能不能发"的判断标准。
4. **`DESIGN.md`**：为什么这样设计，读它能理解链路而非照抄步骤。

## 抖音 9:16 用法

- 做**系列短剧**（10 集以上）：严格按"角色资产 → 分集剧本 → 分镜"走，不要跳步。
- 做**单条 60 秒**：只用"分镜 + 提示词"两个技能就够。
- 它默认偏影视剧节奏（镜头较慢），竖屏要把每集的前 3 秒单独拿出来当钩子设计。
- 漫剧方向（AI 漫画分格 + 配音）是抖音上很吃香的形式，这套链路能覆盖。

## 取用路径

1. `README` 看技能清单 → 挑 2 个与你相关的。
2. `examples/` 看输出长什么样 → 定预期。
3. `skills/` 读那两个的正文 → 用起来。
