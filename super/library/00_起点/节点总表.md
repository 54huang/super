# 节点总表 · 24 个「打开就能抄」的仓库

## 什么叫节点

本库把 50 个仓库里满足这三条的标为**节点**：
1. 交付物是**文本**（md / 词表 / 模板 / Skill），不是权重、不是成片；
2. 有**镜头或约束维度**，能直接影响"怎么拍"而不只是"画什么"；
3. **可以整段粘贴**进模型或 agent，不需要先部署服务。

节点之间不重叠：每个节点在链路上负责一段，交叉引用写在各自的 `Nxx_*.md` 里。

## 组合套路（三种，够用了）

1. **5 分钟出一条信息流视频**：N01/N13 抄一条 → N06 补运镜 → N08 或 N07 定画风 → 出片。
2. **15 秒带货/口播**：N18 出钩子与卖点分镜 → N10 按秒切镜 → N14 五段式填词 → N09 加转场。
3. **不生成、纯动画**：N22 或 N21 选路线 → 04 目录的 shot sheet 管结构 → N23/N22 落成代码 → 02 目录的镜头词表照样用来指导镜头。

## 优先级（如果只装 5 个）

N04（镜头写法的骨架）＋ N06（运镜与负面词）＋ N10（按时间码切镜）＋ N14（五段式填词）＋ N22（不靠模型的动画路线）。
这五个合起来覆盖 01–07 目录的核心能力，剩下的都是各自的加厚版。
