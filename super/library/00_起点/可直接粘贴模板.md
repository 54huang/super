# 可直接粘贴模板 · 从 50 个仓里提炼的 5 套骨架

> 这 5 套不是某个仓库的原文，是把 02/03/04/05 目录里反复出现的结构压成能直接用的骨架。
> 用法：复制骨架 → 只替换【】里的内容 → 其余不要改写（改写会破坏模型的解析习惯）。

---

## 模板 1 · 单镜提示词六段式（9:16，最常用）

```
【主体】25 岁亚洲女性，短发，米色针织衫，左手拿白色马克杯
【动作】缓慢把杯子送到嘴边，视线向下，动作只做这一件事
【环境】清晨厨房，窗外阴天散射光，台面有散落的咖啡豆
【镜头】中近景，平视，85mm 长焦，浅景深，镜头缓慢向右平移 10 厘米
【光线与质感】左侧大面积柔光，暗部保留细节，胶片颗粒轻微，色温 4300K
【约束】9:16 竖构图，主体居中偏上，底部 15% 留空；无文字、无水印、无镜头抖动；人脸不变形
```

要点（来自 N05/N06/N07 的共同做法）：
- **一镜一动作**。动作栏写两个动词以上，翻车率直线上升。
- **镜头栏必须含四件事**：景别、机位、焦段、运动。少一个，模型就自己编。
- **光线栏写方向**，不写形容词。"左侧柔光" > "光线很美"。
- **约束栏放最后**，竖屏比例、留白、禁项、人脸稳定性都写在这一段。

## 模板 2 · 运镜词表（直接抄词，不用抄句子）

| 想要的效果 | 中文写法 | 英文写法 | 常见翻车点 |
|---|---|---|---|
| 推近强调 | 缓慢推近至面部特写 | slow push-in to close-up | 推太快会糊 |
| 拉远交代环境 | 从人物拉远至全景 | pull back to wide shot | 主体容易变小到丢失 |
| 横移跟拍 | 与人物同速向右平移 | tracking shot, moving right | 背景速度易错 |
| 环绕 | 以人物为轴心缓慢环绕 90° | slow 90° orbit around subject | 半张脸会崩 |
| 升降 | 从腰部高度升至俯视 | crane up to high angle | 透视突变 |
| 手持跟随 | 手持跟拍，轻微呼吸感晃动 | handheld follow, subtle breathing shake | 抖动过大像地震 |
| 第一视角 | FPV 第一人称穿越 | FPV drone, immersive POV | 需要明确路径（见 `02/zhouwei713`） |
| 固定机位 | 三脚架固定，仅人物动作 | locked-off tripod, no camera move | 长时间会"死"，配动作才成立 |
| 变焦压缩 | 长焦压缩空间，背景贴近主体 | telephoto compression | 与"推近"混用会冲突 |

规则：**一条提示词里只允许一个主运镜**，需要叠加时用「主运镜 + 轻微」的写法（如"横移为主，轻微手持感"）。

## 模板 3 · 视频专属负面约束（比通用负面词更管用）

```
画面：不要 morphing（形体融化）、不要闪烁、不要帧间跳变、不要五官漂移
人物：不要身份漂移（前后不像同一人）、不要多手指/断肢、不要表情抽搐
文字：不要生成文字、不要字幕乱码、不要水印、不要台标
镜头：不要无意义推拉、不要镜头抖动、不要突然变焦、不要画面撕裂
风格：不要塑料感、不要过曝、不要过度锐化、不要 HDR 味、不要 AI 油画感
构图：不要居中大头贴（竖屏除外）、不要主体被裁切、不要底部被 UI 遮挡区放关键信息
```

用法：负面段单独成段放在提示词末尾；如果平台有独立 negative prompt 字段，只填物体类负面（文字/水印/多余手指），风格类负面留在正文里，避免过度压制导致画面发灰。

## 模板 4 · 画风锚点（跨镜头一致性的关键）

把下面压成一条**不超过 40 字**的固定字符串，每个镜头原样复制，一个字都不改：

```
【画风锚点】Q 版手绘蜡笔质感，米黄纸底，暖橙主色 + 墨绿点缀，粗描边，无渐变
```

再补三条独立锚点：
- **人物锚点**：发型/服装/配饰（"黑色短发，圆框眼镜，藏青卫衣"）
- **光源锚点**：方向 + 色温（"左上 45° 暖光，4300K"）
- **构图锚点**：主体位置（"主体居左三分线，右下留白放字幕"）

四个锚点固定后，剩下的才可以自由发挥 —— 这是 `03/kaomei`、`03/popopo-99`、`02/smixs` 三家的共同做法。

## 模板 5 · 分镜脚本 JSON 骨架（给 agent 用，也给人用）

```json
{
  "project": "【项目名】",
  "format": { "ratio": "9:16", "fps": 30, "total_sec": 30, "safe_area": "底部15%/右侧12%" },
  "style_anchor": "【画风锚点字符串】",
  "shots": [
    {
      "id": "S01",
      "start": 0.0, "end": 4.0,
      "purpose": "钩子：制造疑问",
      "shot_size": "中近景",
      "camera": "固定机位，轻微手持",
      "subject": "【主体】",
      "action": "【单一动作】",
      "light": "左上45°柔光",
      "prompt": "【六段式填好的完整提示词】",
      "negative": "【模板3 精简版】",
      "subtitle": "【这一镜的字幕文案，≤14字】"
    }
  ]
}
```

切镜三条硬规则：
1. **先定时间轴再写画面**：总时长 ÷ 单镜上限（4/6/8/10 秒）＝ 至少几个镜头，镜头必须无缝覆盖、不重叠。
2. **每镜只承担一个叙事功能**：钩子 / 佐证 / 转折 / 结论，功能重复的镜头删掉。
3. **字幕按镜切，不按句切**：一条字幕 ≤16 字符（不含空格），跨镜的句子要在语义停顿处断开。

（这套结构与 `04/geeklee` 的"时间码驱动"、`04/neopen` 的"分镜片段"、`05/huangbai-AI` 的"五段式"可以互相映射，任选其一落地即可。）
