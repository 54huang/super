## 取用顺序

1. **先定画风锚点**（N08 的四锚点法）：画风、人物、光源、构图，各一句话，全片复用。
2. **再定质感**：用 N07 的"光源方向 + 遮挡 + 距离"压真实感，或用 N07/N15 的 LOOK 迁移做风格统一。
3. **单独处理特效镜**（N09），不要混进主镜头。
4. **最后加负面**（N06 视频专属 + N16 的方法论），放在末尾。

## 一致性检查清单（出片前过一遍）

- [ ] 人物：发型/服装/配饰三个描述在每个镜头里**逐字相同**
- [ ] 光源：方向与色温没变（一镜左光一镜右光＝穿帮）
- [ ] 色板：主色 + 点缀色不超过 2 个
- [ ] 画幅：全是 9:16，没有混进 16:9 再裁
- [ ] 质感：颗粒/锐化/对比度描述一致，没有一镜"胶片"一镜"数码"
- [ ] 负面段：每个镜头都带了，没有漏
