## 为什么是节点

**本库里唯一为 9:16 竖屏原生设计的仓**。输入是中文口播文案，输出是：4-6 秒语义镜头 + 视觉隐喻 + 英文生图 Prompt + 图生视频 Prompt + 内嵌手绘关键词。它明确解决三个竖屏痛点：**画风漂移、背景不统一、字幕遮挡**。

## 它能给你什么

1. **语义切镜法**：不是按字数切，是按"一句话一个意思"切，4-6 秒一镜 —— 这对知识类/财经类口播是标准解法。
2. **视觉隐喻的写法**：抽象概念（通胀、效率、内卷）怎么变成具体画面，这套给了套路。
3. **画风基线 + 字幕避让**：画风关键词固定成基线，全片复用；字幕区在构图时就留出来。
4. **`outputs/`**：直接看成品，判断这套风格是否适合你的账号。

## 抖音 9:16 用法

这就是抖音原生范式，几乎不用改：
- 口播文案 → 按语义切成 4-6 秒 → 每镜一句隐喻 → 出图 → 图生视频（轻微动效即可，手绘风不需要大运镜）。
- 手绘风的镜头运动**只做推、拉、轻微平移**，做环绕必崩。
- 字幕留白放在底部 15% 以上，主体永远不进入这条带。

## 取用路径

1. `demo/` → `outputs/` 看效果。
2. 读 Skill 正文的切镜规则 → 拿自己的一条口播稿练一遍。
3. 需要画风升级时，去 03/N07 补真实感（但注意两者风格互斥，别混）。

## 注意

风格是"Q 版蜡笔手绘"，**强绑定**。做别的画风时抄它的**方法**（语义切镜、画风基线、字幕避让），不要抄它的关键词。
