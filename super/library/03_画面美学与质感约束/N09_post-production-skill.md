## 为什么是节点

填补了 02/03 目录的一个空档：**"特效镜"的写法**。普通镜头写"人物 + 动作 + 镜头"，但转场、光效、界面动效、合成感画面是另一套语法 —— 混进主镜头会把主镜头写坏。这个仓把它单独拎出来了。

## 它能给你什么

1. **VFX 措辞**：光爆、粒子、能量场、材质崩解这类效果的写法（关键是写"效果如何发生的时间顺序"，不是堆名词）。
2. **创意转场**：两个镜头之间怎么"缝"——遮罩、甩镜、同形转场、光斑过渡。
3. **三维 UI / 动态图形**：科技感界面浮层、数据流、扫描线，适合做科技类/数码类内容的图形层。
4. **视觉合成提示词**：多元素叠在一帧里时的层次描述（前后景、透明度、光照一致性）。

## 抖音 9:16 用法

- **转场单独成镜**：一条 0.4-0.8 秒的转场镜头，别塞进 4 秒主镜头里。
- 竖屏的特效"面积"要小：全屏粒子在窄画幅里像故障，改成"局部光斑/边缘光"。
- 做数码、汽车、科技产品时，三维 UI 层是提质感最快的手段 —— 但一定要写"界面元素位于主体右侧，不遮挡人脸"。

## 取用路径

1. 读完 README 的特效分类，整理成"我可能用到的 5 种"。
2. 每种抄一条，做 2 秒测试片，确认模型能吃。
3. 稳定后再进正式分镜。

## 注意

特效镜**出片率低**（比普通镜头更容易崩），预算要留余量；不要在一部片里用三种以上特效，会显得廉价。
