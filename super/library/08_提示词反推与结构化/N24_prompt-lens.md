## 为什么是节点

做内容最快的路径不是"想"，是**拆解已经跑通的东西**。它做三件事：画面分析（构图/主体/风格）、音频识别（把台词文案提取出来）、一句话剪辑。README 的定位很直白：刷到喜欢的 AI 视频，一键学习复刻它的创意与脚本。

## 它能给你什么

1. **画面分析 → 提示词**：把成片拆成"可写进提示词的要素"，省掉你自己逐帧看的时间。
2. **音频识别 → 文案**：口播内容的台词直接拿到，这是做"同结构不同内容"的基础。
3. **完整的创作闭环设计**：发现灵感 → 拆解 → 改写 → 出片，四步都被产品化了，可以照这个流程做自己的 SOW。
4. **可自部署**：数据在自己手里，适合长期做对标库。

## 抖音 9:16 用法

- 选定 3-5 个对标账号，每条爆款拆一次，攒成**自己的"结构库"**（不是文案库）。
- 注意：拆出来的是**结构与节奏**，主体内容必须换掉，否则就是搬运。
- 竖屏拆解时重点看三件事：前 3 秒给了什么信息、每几秒切一次、字幕出在哪。
- 拆完的结构直接填进 `00_起点/可直接粘贴模板.md` 的分镜 JSON。

## 取用路径

1. `docs/` 看流程与截图 → 判断是否要自部署。
2. 本地起服务 → 拆 1 条对标视频 → 对比自己原来的写法。
3. 把拆解结论沉淀成表格（配合 N19 的 SOP）。

## 注意

反推出来的提示词**通常不能直接用**：它是"还原版"，而你要的是"新内容 + 同样的镜头逻辑"。务必换主体。
