# 08 · 提示词反推与结构化

**收录逻辑**：把"已有的东西"（别人的片子、自己的粗想法、一堆散句）转成**结构化的提示词**。这是提效最快的一层 —— 不用从零想，先拆再改。
**什么时候来**：刷到一条好片想复刻结构；或者自己的提示词越写越乱、模型理解不了。

## 反推的标准动作（四步）

1. **抽帧**：按 1-2 帧/秒抽，先看"切点在哪"（画面差异最大的相邻帧就是切点）。
2. **分层拆**：这一镜里分别拆出 —— 主体、动作、环境、景别、机位、运动、光线、色调。
3. **填回骨架**：按 `00_起点/可直接粘贴模板.md` 的六段式填，缺的项标"待定"，别自己编。
4. **换主体不换结构**：结构是别人的经验，主体要换成自己的，否则就是搬运。

## 为什么"结构化"比"写得更长"有用

模型对提示词的处理是**按段落分配注意力**的。把"人物、动作、镜头、光线、约束"分段写，比写成一大段形容词堆叠的散文，出片稳定性高一个档 —— 这也是 01/05 目录里几乎所有高质量库的共同特征（五段式、六段式、分段 JSON 都是同一个道理）。
