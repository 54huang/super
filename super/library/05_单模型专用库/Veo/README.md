# Veo 专用

Google 的 Veo 3 系**原生带音频**（对白、环境声），所以提示词结构上多一段"声音"。画面描述相对克制，长句也能吃。

## Veo 的四段写法

```
【画面】场景 + 主体 + 一个动作
【镜头】景别 + 机位 + 运动（一句）
【声音】环境音 + 谁在说话 + 台词原文（没有就写"无人声，仅环境音"）
【限制】无字幕、无水印、无文字
```

要点：
- 声音段别省 —— 不写的话它会自己编对白或加音乐。
- 台词用引号括起来，模型更容易原样念出。
- 竖屏要显式写 `9:16`，Veo 默认偏横。
