## 海螺 H3 的两个习惯

1. **首帧描述单独一段**：H3 对"这一帧长什么样"和"接下来怎么动"分得很开，混写会两头不讨好。
2. **人物表演要写微动作**：眼神方向、嘴角、手指、呼吸 —— 写"她在难过"没用，写"她垂下眼，拇指摩擦杯沿"才有用。
