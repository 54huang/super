# Grok Imagine 专用

xAI 的 Grok Imagine，生成速度快、风格化强，社区库以题材分类为主（电影感、动作、动漫、产品、梗图）。

| 仓库 | ★ | 来源与定位 | 具体参考用途 | 节点 |
|---|--:|---|---|:--:|
| [YouMind-OpenLab/awesome-grok-imagine-prompts](https://github.com/YouMind-OpenLab/awesome-grok-imagine-prompts) | 57 | 按风格分类的 Grok Imagine 提示词集合，持续更新 | 做**梗图/快节奏网感内容**时的措辞参考；同一题材能对比多种风格写法 | - |

## 适用与不适用

- 适合：网感强、节奏快、风格夸张的竖屏内容；快速试错。
- 不适合：需要精细镜头控制与跨镜一致性的商业片 —— 这类回到 02/03 用结构化写法。
