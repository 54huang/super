## 为什么是节点

**本库最值得先抄的一个结构**。它把 Seedance 2.5 的提示词压成五段：**主体 → 风格 → 时间线 → BGM → 限制**。五段填完基本不会漏项，而且"时间线"这一段是大多数人的盲区 —— 它要求你写清"第几秒发生什么"。

## 它能给你什么

1. **五段式模板**：稳定、可复用、可交接（给同事看也知道每段该写什么）。
2. **时间线写法**：把"动作"变成"时刻表"。这是从"会动的图"升级到"镜头"的关键一步。
3. **BGM 段**：音乐情绪也写进提示词，出片后的后期会省事很多（尤其卡点内容）。
4. **15 个真实案例**（`references/examples.md`）：改一个变量看结果差异，比自己瞎试快。

## 抖音 9:16 用法

- 直接当主模板：
  ```
  主体：【谁 + 外观固定描述】
  风格：【画风锚点 + 色调 + 质感】
  时间线：0-2s【动作一】；2-4s【动作二或镜头变化】
   BGM：【节奏型 / 情绪 / 有无鼓点】
  限制：9:16，无文字水印，主体不被裁切，无镜头抖动
  ```
- 竖屏一条片子里，**每镜都写时间线**，避免镜头"空转"。
- BGM 段对卡点视频尤其重要：写"每 1.2 秒一个重拍"，剪辑时有依据。

## 取用路径

1. `SKILL.md` 读五段定义。
2. `references/examples.md` 挑 3 条改写成自己的题材。
3. 把五段式与 00_起点 模板 1 的六段式对照，选一个作为长期模板（**不要两套混用**）。
