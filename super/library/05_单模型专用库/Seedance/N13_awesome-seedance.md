## 为什么是节点

Seedance 是竖屏短视频最常用的一档，而这是同类里**质量与更新频率最好**的：`prompts/` 存提示词、`videos/` 存成片，一一对应。有中文 README，不用翻译。

## 它能给你什么

1. **提示词 ↔ 成片对照**：判断"这句到底有没有用"的唯一可靠方法。同一条提示词的成败都在眼前。
2. **写法惯例**：Seedance 系的叙述顺序（主体 → 动作 → 环境 → 镜头 → 风格 → 限制）在这个库里被反复使用，照着这个顺序写，稳定。
3. **题材覆盖面**：电影感、动漫、UGC、广告、产品、梗图风格齐全，做垂类账号能直接找同类。
4. **`videos/` 当预期管理工具**：先看你能拿到什么效果，再决定投入多少。

## 抖音 9:16 用法

- 库里横屏居多，**取用时先补画幅与留白**："9:16 竖构图，主体居中偏上，底部 15% 留空放字幕"。
- 单镜时长按 4/6/8 秒取整。
- 限制段固定：无文字、无水印、无镜头抖动。
- 挑 3 条同风格作为画风基底，把风格串固定下来（见 00_起点/模板 4）。

## 取用路径

1. `README-zh.md` 目录 → 找同题材。
2. `prompts/` 复制 → 换主体 → 补竖屏约束。
3. 出片不对 → 回 02/N06 补运动维度。

## 注意

星数高不代表每条都好 —— 社区库水平参差，**优先看有 `videos/` 对照的条目**，没有成片的提示词不要信。
