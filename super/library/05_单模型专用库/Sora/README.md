# Sora 专用

OpenAI 的 Sora 系对**长句叙述**的容忍度比国内模型高，但对"镜头术语"的解析不如专业影视词表精确 —— 所以常见做法是：用自然语言写画面与动作，用 05 之外的专业词表（02 目录）压镜头。

| [SoraEase/sora-prompt-zh](https://github.com/SoraEase/sora-prompt-zh) | 129 | 中文提示词技巧与"调教指南"，覆盖多场景使用 | **短视频场景首选**：它讨论的是"怎么让它听你的话"，而不是堆案例 | N15 |

## 写 Sora 提示词的三条经验（跨两个仓归纳）

1. **一段话只描述一个连续动作**：Sora 擅长"运动过程"，不擅长"多个动作的因果关系"。
2. **把镜头写进句子里，而不是另起一段参数**：如"镜头以缓慢的横移跟随她走出画面"，比"camera: pan right"更有效。
3. **结尾写"不要什么"**：文字、水印、镜头抖动这三项几乎必写。
