## 为什么是节点

Remotion 本身很强但学习曲线在"时间轴思维"；这个 Skill 的作用是**把时间轴翻译成 agent 能执行的任务** —— 你说"3 秒处标题从左滑入，0.5 秒缓动"，它写组件。做**字幕动效、数据片、产品发布片、模板化量产**时，这是效率最高的一条路。

## 它能给你什么

1. **动态图形范式**：缓动曲线、层次、同步 —— 这些在 AI 生成里根本控不了，在代码里是参数。
2. **字幕/字效**：逐字出现、弹跳、描边、霓虹，可精确到帧。
3. **模板化**：一套组件换数据就能出 N 条片子（做矩阵号的关键）。
4. **与生成式混用**：AI 生成的素材当背景层，Remotion 做前景图形层，两者用同一时间轴对齐。

## 抖音 9:16 用法

- 1080×1920 / 30fps，Remotion 里就是 `width=1080, height=1920`。
- 竖屏动效三条原则：**上下分区**（信息在上、主体在中、字幕在下）、**单向运动**（一次只一个方向动，别多向齐发）、**0.3 秒法则**（入场动效不超过 0.3 秒，否则显得慢）。
- 做"数据说话"类内容（涨跌、对比、排名），Remotion 的正确率是 100%，AI 生成是 0%。

## 取用路径

1. 根 README 装 Skill → 让它生成一个 5 秒测试片。
2. 跑通后把常用动效存成自己的组件库。
3. 需要底层能力（音频、序列、渲染配置）时看 `07/remotion` 官方仓。

## 注意

需要 Node + React 基础。纯创意岗可以让 agent 代写，但你得能说清"第几秒、什么元素、从哪到哪"。
