## 为什么是节点

它把**运动设计当一等维度**：运镜 / 时序 / 主体运动 / 物理连续性，四个维度分开写。绝大多数提示词库只写"画什么"，不写"怎么动、动多久、动完停在哪"——而后者才是"像视频"和"像会动的图"的分水岭。另外它附了**视频专属负面词库**（morphing、闪烁、身份漂移、文字漂移）。

## 它能给你什么

1. **四维运动拆法**：一个镜头按"谁在动 / 镜头怎么动 / 动的顺序 / 物理上合不合理"四问写完，几乎不会出现"人物飘着走"。
2. **视频专属负面词**：比通用负面词更对症。直接放进提示词末尾。
3. **跨镜一致性锚点**：多镜头序列里防止"每镜换个人"。
4. **10+ 平台的语法适配**：可灵/即梦/海螺/清影/通义万相/Sora/Runway/Veo/Luma/Pika，换平台只改外壳。

## 抖音 9:16 用法

- 竖屏最怕"飘"，四维里的**物理连续性**要重点写（重力方向、接触面、惯性）。
- 负面词直接抄，注意竖屏额外加一条"不要主体被上下裁切"。
- 卡点内容：把"时序"写成秒数（"第 1 秒抬手，第 2 秒落下"），比"快速"有效得多。

## 取用路径

1. `SKILL.md` 读四维定义 → 拿一条自己写过的提示词按四维补全。
2. `references/` 取负面词与一致性锚点。
3. 回 03 目录压质感。
