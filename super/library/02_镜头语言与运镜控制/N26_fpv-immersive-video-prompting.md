## 为什么是节点

别的库教你"这一镜用什么词"，它教你**镜头从哪里出发、按什么顺序经过谁、最后停在哪**。同一个 FPV 需求，猫在咖啡厅走和无人机穿大陆是两套完全不同的写法，它把这两种拆成了两条明确的路由。这是 02 分类里唯一一个"运动优先于画面"的仓库。

## 它能给你什么

1. **八个必答问题**：摄像机是谁 / 从哪开始 / 有几个主体 / 按什么顺序经过 / 每段是否物理可达 / 每个停靠点发生什么 / 哪些身份必须一致 / 什么绝对不能出现。
2. **两种路线模式**，选错就崩：
   - **编号停靠点**——室内、近距离人物互动。首帧上打 1/2/3 小编号，路线交给提示词约束，**不画红线**（红线会穿桌椅、穿人腿，还容易残留在成片里）。
   - **红线路径控制**——大世界航拍、城市穿越、赛车线。红线画在路线规划图上，正片里必须彻底消失，提示词要显式写"不要出现红线、箭头、标注、地图感"。
3. **生图资产包**：N 个主体就出 N+2 张图（1 张带编号首帧 + N 张人物参考 + 1 张干净首帧）。首帧管空间，参考图管身份，干净首帧才是喂给视频模型的输入——只给一张图，模型会把路线标记和画面内容混在一起。
4. **翻车清单**：瞬移、主体数量漂移、编号残留、猫视角变无人机视角、说一镜到底却跳切。

## 抖音 9:16 用法

- 竖屏 FPV 的最大风险是**前景全糊**：两侧没有横向余量，贴着地形飞的一瞬间整个画面是一块墙。提示词里加一句"保留可辨认的前景参照物（桌腿/栏杆/门框）"，模型才有参照。
- 一镜到底的竖屏最多撑 6–8 秒，超过就没人跟得住了。15 秒的内容拆成 2–3 个 FPV 段，段之间用"停在某处"收尾（它叫停靠点），别用切镜硬接。
- 猫咪/宠物视角是竖屏最吃香的一类：低机位天然填满画面，且能避开头像区。

## 取用路径

1. 先过 `SKILL.md` 的八个问题，把答案写成一行行短句。
2. 判断走"编号停靠点"还是"红线路径"，直接抄 `examples/numbered-stop-example.md` 或 `examples/redline-route-example.md` 的结构。
3. 需要首帧资产包时看 `skill/references/gpt-image-asset-packs.md`。
4. 一句话就能让 agent 按这套跑：`帮我做一个咖啡厅里 3 个人依次互动的 FPV，15 秒，猫咪视角`。

## 注意

- 它只管**运动与空间**，不管表演、台词、情绪——那些得回 N07 / N27。
- 红线模式依赖平台支持路径控制（Seedance 2.0 这类），普通图生视频模型不认红线，只能当构图参考。
- 编号方案有个副作用：编号画在首帧上，模型有一定概率把它画进正片。所以它才要求再出一张"干净首帧"——这一步不能省。
