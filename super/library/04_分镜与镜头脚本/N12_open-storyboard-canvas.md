## 为什么是节点

文字分镜的通病是**机位想不清楚** —— 写"过肩镜头"，脑子里其实没有那个机位。这个工具把机位变成可视化的东西：全景图上摆摄像机、调角度，提示词跟着机位走。对"镜头语言还没内化"的阶段，比读十篇教程有用。

## 它能给你什么

1. **摄像机控制的界面化**：机位、朝向、景别用拖拽表达，避免"文字描述的机位和脑补的不一样"。
2. **提示词预设**：常用镜头组合存成预设，下次一键套 —— 这就是把 02 目录的词表变成可复用的按钮。
3. **自定义供应商**：可以接自己的模型，不锁定平台。
4. **分镜的"总谱"视图**：一屏看到所有镜头的关系，方便调顺序。

## 抖音 9:16 用法

- 画布设为 9:16 竖幅再摆机位，否则摆出来的构图到手机上会变。
- 竖屏的机位基本只有四种：平视中近景、俯拍桌面、仰拍人、过肩/前景遮挡。先把这四种摆熟。
- 一个片子的机位不要超过四种，多了观感会碎。

## 取用路径

1. 读 README 起本地服务。
2. 建一个 9:16 项目 → 摆 4 个机位 → 导出提示词。
3. 与 04/N05 的镜头清单格式对照，选一种作为自己的主工作流。

## 注意

它是**工具**不是词库 —— 提示词质量取决于你输入的词表，先把 02 目录的词表准备好再用它。
