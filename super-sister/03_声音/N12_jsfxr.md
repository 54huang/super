## 为什么是节点

因为**"贴纸贴上去的那一声"不该去找素材，该被算出来**。

这类音效（点击、落定、翻页、弹出、碎裂）在素材库里搜"paper"能得到几百条，但每条的时长、音高、明暗都不一样，混在一部片里会很散。**参数化生成的好处是：所有落点音来自同一个生成器，天然是一家人**——只是参数微调。

它的原理极简：一段波形（方波/锯齿/正弦/噪声）× 一条频率包络（从高扫到低）× 一条振幅包络（指数衰减）× 时长。五六个参数，就能覆盖 8-bit 时代所有的"哔、啪、嗒、轰"。

## 它能给你什么

1. **五个参数造一个音**：波形、起始频率、滑音方向与幅度、包络衰减、时长、占空比。**改其中两个就换一种"材质感"**——短的方波是"啪"（纸），长的下滑锯齿是"咔"（木头），噪声 + 快衰减是"沙"（摩擦）。
2. **确定性**：同参数必同音。这意味着你可以"给每个镜头算一个变体"，而不用手工挑。
3. **`riffwave.js`**：把生成的采样直接打包成 WAV 文件，浏览器里就能下载。**这是把"网页生成"接进"离线出片"的桥**。
4. **rfxgen 能命令行批量**：要产出几百个变体（比如每个镜头的落点音都不完全一样）时，写个循环跑 rfxgen。
5. **Unlicense / Zlib**：不用署名、不用开源、商用随便。**本库许可最干净的两个仓。**

## 怎么落到 9:16 竖屏

竖屏片的落点音有三个硬要求，参数照这个调：

| 要素 | 值 | 为什么 |
|---|---|---|
| 时长 | **60–120ms** | 超过 200ms 就变成"音效"而不是"落点"，会拖慢节奏 |
| 起始频率 | 800–2000Hz | 手机小喇叭在 500Hz 以下几乎没声，太低等于没做 |
| 衰减 | 指数、几乎到底 | 线性衰减听起来像"被掐断" |
| 音量 | 比人声低 6–8dB | 落点音是"垫"的，不是"主角" |

- **同一个动作系列用同一个参数模板**，只改 1–2 个数字。一部片里 6 个落点音用 6 个完全不同的音色，会像音效包拼贴。
- 竖屏节奏比横屏快，**落点音要比动作完成早 0–1 帧**（人耳对"声音早到"的容忍度远高于"声音晚到"）。

## 取用路径

1. 开 `index.html`（网页生成器），先随便点几个预设，听清"哪种波形像哪种材质"。
2. 定一个模板：波形 + 包络形状 + 时长。
3. 用 `sfxr.js` 的 API 批量生成变体 → `riffwave.js` 导出 WAV。
4. 要几百个 → 改 rfxgen 的 `src/` 写命令行批处理。
5. 混进片子时按上表压低音量。

## 注意

- 它只会做 **8-bit 风格**。要"真实纸张撕裂"还是得用采样（N13）。
- 生成的是**单声道短采样**，不要企图用它做垫乐。
- jsfxr 的网页版有历史包袱（它源自 sfxr，代码很老），读 `sfxr.js` 时只看"参数 → 采样"那一段，UI 部分别管。
- `sfxr-to-wav/` 是命令行工具，批量导出走这条路比在浏览器里一个个点快得多。
