# 03 · 声音

> 这一层解决**画面动一下，耳朵听到什么**：落点音、垫乐、环境声、对拍。
> 这是全库最容易被拖到最后、也最容易毁掉前面两层的一层——声音不对，观众说不出哪不对，但就是"假"。

**收录逻辑**：**能造出声的实现**（合成器、参数化音效、采样库、分析工具）。本库**不建非 GitHub 的音效素材清单**——需要时现取，见 `00_起点/需求速查.md` 末节。
**什么时候来**：贴纸贴上去没有声音；转场没有落点；垫乐一垫就盖住人声；字幕跟语音差半拍。

## 取用顺序

1. **先分清三类声音**：**落点音**（几十毫秒，要有"啪/嗒/沙"的实感）／**垫乐**（整片不断，不能抢人声）／**环境声**（风、街、室内底噪）。三类做法完全不同，别混。
2. **落点音 → N12** 现造（几十毫秒一个，参数微调就能配不同镜头）。
3. **要真实材质声（纸、木、布、水） → N13 的 `etc/samples/`** 先翻 CC0 采样；翻不到再造。
4. **垫乐 → N11** 现场合成（可控、无版权），或 N15 的音色 + 自己写的和弦进行。
5. **最后一定要过 N14**：量出人声每个字的起音时间，把画面切点对齐到它。这一步做完，整片会突然"专业"。

## 四条关键认知

- **配乐按 RMS 归一到人声之下 12dB，不按峰值。** 一条几乎全是低频正弦的垫乐，按峰值归一到 −6dBFS 时 RMS 会到 −18dBFS，比人声还响。正确做法：目标 RMS ≈ −34dBFS，同时峰值不高于 −10dBFS。
- **混流时不要再跑一次响度归一化。** 人声已经归到目标响度，混的时候再 `loudnorm` 会把垫乐一起抬上来、反压人声。只压垫乐音量、直接叠。
- **`loudnorm` 报的 `output_i` 是预测值，不是成片电平。** 别拿它判断"要不要保留归一化"，要量产物。
- **声音的"落点"比音色重要。** 一个普通音效如果正好卡在动作完成的那一帧，观感远好于一个精美音效晚 80ms。
