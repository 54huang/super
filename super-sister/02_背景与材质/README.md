# 02 · 背景与材质

> 这一层解决**东西站在什么环境里**：街道、地图、雾、光、墙面、水。
> 它不画主体，只画底。但一条竖屏片"在不在那个地方"，八成由这一层决定。

**收录逻辑**：**能当背景板用的生成器**，或**决定质感的环境算法**（着色器、程序化材质）。不是图库——本库不收实景照片。
**什么时候来**：主体画好了但背景空得假；要"海安那条街"但找不到素材；要雾/光/水纹但不想用滤镜；要一张能商用的抽象底。

## 取用顺序

1. **先问"这个背景要不要能被读出来"**。要（观众得认出是"海安的街"）→ N07/N08 地图系；不要（只要氛围）→ N09/N10 着色器与材质。
2. **要能被读出来的，一定分层**：底（水/绿地）→ 中（建筑体块）→ 顶（道路/文字）。单层画出来的地图永远是"一块颜色"。
3. **要贴图的走 N10，要光的走 N09**。两者不冲突：材质给表面，着色器给光照与雾。
4. **导出即锁死**：背景出成静帧 PNG 就别再在合成软件里二次缩放，程序化线条一缩放就抖。

## 三条关键认知

- **背景的功能是"提供对比"，不是"提供细节"。** 竖屏 1080 宽，背景最多占 40% 的信息量；细节堆太多，主体反而读不出来。这就是为什么 N09 那本书里最有用的是"噪声"和"fBm"两章，不是"光线追踪"。
- **地图类背景有个陷阱**：OSM 数据是"真实但不美"。直接渲染出来街道密度不均（市中心糊成一片），必须先按等级过滤（只留主干 + 少量支路）再上色。
- **许可在本层最危险**。这一层 7 个仓里 3 个是 GPL/AGPL、1 个是保留所有权利——因为"地图海报"和"着色器教材"这两类项目最容易被大公司收编，作者也更在意许可。抄之前一定看 LICENSE 原文，别看仓库简介。
