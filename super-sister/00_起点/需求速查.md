# 需求速查 · 「我要画 XX」→ 去哪

> 用法：先在下面找到你要画的东西，再点节点看细节。**找不到就按"它由哪几块组成"拆**——本库没有"直接画出整袋栗子"的仓，但袋身、袋口、内容物、蒸汽各有出处。

## 一、按物件查

| 我要画… | 去这里 | 关键做法 |
|---|---|---|

## 二、按声音查

| 我要… | 去这里 | 关键做法 |
|---|---|---|
| **"啪 / 嗒 / 沙"的落点音** | [N12](../03_声音/N12_jsfxr.md) | 60–120ms、起始 800–2000Hz、指数衰减到底 |
| **真实材质声（纸、木、布、金属、摩擦）** | [N13](../03_声音/N13_sonic-pi.md) → `etc/samples/` | 整套 CC0 `.flac`，先翻再合成 |
| **环境底（风、街、室内）** | [N13](../03_声音/N13_sonic-pi.md) → `ambi_` 开头的 | 取 8–15 秒循环段，压低 20dB 铺底 |
| **垫乐 / 氛围和声** | [N11](../03_声音/N11_tone-js.md) 或 [N13](../03_声音/N13_sonic-pi.md) | 三层：垫音 + 稀疏拨弦 + 低频；**RMS 压到人声下 12dB** |
| **真钢琴 / 真弦乐** | [N15](../03_声音/N15_soundfonts.md) | 只加载用到的 3–4 个八度；音高偏移别超 ±2 半音 |
| **字幕对不齐语音** | [N14](../03_声音/N14_librosa.md) | `onset_detect` 量起音，别用字数估 |
| **画面卡点卡不准** | [N14](../03_声音/N14_librosa.md) | `beat_track` 找重拍，切点挪到最近的拍 |
| **声音在网页里播放** | [N11](../03_声音/N11_tone-js.md) | `Tone.Transport` 音频时钟；注意自动播放策略要在手势后 `resume()` |
| **声音可视化（频谱/波形）** | [N14](../03_声音/N14_librosa.md) | 离线算 `stft` 存成数组，比实时分析更可控 |

## 三、按"出问题了"查

| 症状 | 真正的原因 | 去哪 |
|---|---|---|
| 逐帧渲染重跑一次，画面全变了 | 用了 `Math.random()`，没播种 | [N06](../01_程序化画事物/N06_noise.md) |
| 烟/光的边缘有硬边 | 用单层渐变或模糊去补 | [N09](../02_背景与材质/N09_thebookofshaders.md) 的 fBm + 多层叠加 |
| 手绘风看着像毛刺 | 直接在几何上加噪声，没分"中间大两端小" | [N04](../01_程序化画事物/N04_rough.md) |
| 线条生长满屏乱跳 | 没做笔序优化 | [N05](../01_程序化画事物/N05_vpype.md) |
| 背景比主体抢眼 | 背景信息量 >40%，或饱和度没压 | [N07](../02_背景与材质/N07_city-roads.md) / [N08](../02_背景与材质/N08_prettymaps.md) |
| 地图糊成一片 | 支路没过滤 | [N07](../02_背景与材质/N07_city-roads.md) |
| 配乐一进来人声听不清 | 按峰值归一而不是 RMS | [N11](../03_声音/N11_tone-js.md) / [N13](../03_声音/N13_sonic-pi.md) |
| 混流后整体响度不对 | 混的时候又跑了一次 loudnorm | [N11](../03_声音/N11_tone-js.md) 的「注意」 |
| 改画布尺寸后全崩 | 像素参数写死，没按画布宽归一 | 三栏 README 的「硬规矩」第 3 条 |

## 四、GitHub 之外的东西，用时现取（本库不建清单）

按你的要求，音效这一类**不单独立项**，也不额外维护一份非 GitHub 的素材清单。真需要超出以下范围时，只记三个去处，用时直接搜：

- **Kenney**（CC0，无署名要求）：成套游戏音效，分类齐全。
- **Freesound**（筛 CC0）：按"纸 / 撕 / 摩擦 / 木头"逐个搜，比整包下载精准。
- **Pixabay Audio**（CC0 类）：垫乐与环境音，质量参差但能商用。

**但先去 [N13](../03_声音/N13_sonic-pi.md) 的 `etc/samples/`** —— 那是 GitHub 上现成的整套 CC0 采样，多数情况下够用，且不用注册、不用点下载按钮。
