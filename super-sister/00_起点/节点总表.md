# 节点总表 · 15 个「打开源码就能抄」的仓库

## 什么叫节点

本库把 24 个仓库里满足这三条的标为**节点**：
1. 交付物是**可读的实现**（源码 / 着色器 / 参数表 / 采样），不是宣传页、不是成片；
2. 有**明确的画法主张**（分层、噪声、约束、参数化），而不只是"又一个绘图 API"；
3. 能**关掉网络跑**，或至少能看懂并重写，不依赖某个在线服务。

节点之间不重叠：每个节点负责一段，交叉引用写在各自的 `Nxx_*.md` 里。
**15 个节点分布在 18 个仓上**——有 3 个节点是两仓合并（N06 噪声、N12 参数化音效、N13 音乐环境+采样）。

## 三条组合套路

1. **"用代码画一条街的片子"**：N07 出街网 → N05 排队笔序 → N01 补树与人 → N09 加雾 → N11/N12 配声 → N14 对拍。
2. **"量产系列片，每集不一样"**：N06 固定种子 + N01 的分带规则 + N07 的地名做参数 → 同一套代码换输入就换片（此时**画面随参数变，但结构不变**）。
3. **"只说一件事的产品片"**：N03 出线稿 → N04 加手绘感 → N10 出纸/布底 → N12 造落点音。

## 优先级（如果只装 5 个）

**N01**（自然物怎么拆）＋ **N04**（手绘线怎么抖）＋ **N06**（随机怎么锁）＋ **N13**（采样从哪来）＋ **N14**（声音怎么对拍）。

这五个覆盖三栏的地基：形从 N01/N04 来，可控性靠 N06，声从 N13/N14 解决。剩下的都是各自的加厚版。
