## 1. 山的轮廓：包络 × 噪声

**来源**：[shan-shui-inf](https://github.com/LingDong-/shan-shui-inf)（MIT）的 `Mount.mountain`
**要点**：先给余弦包络定出"中间高、两端落回基线"的基本形，再乘噪声打碎边缘。**顺序不能反**——直接用噪声当高度，画出来是一排锯齿，没有山的样子。

```js
// w：画布宽 · baseY：基准线（山脚）· h：山高 · noise2(x, seed) → -1…1
function mountainPath(ctx, w, baseY, h, seed, noise2) {
  const COLS = 48;
  ctx.beginPath();
  ctx.moveTo(0, baseY);
  for (let i = 0; i <= COLS; i++) {
    const u = i / COLS;                        // 0…1 横向位置
    const env = Math.cos((u - 0.5) * Math.PI); // 包络：中间 1，两端 0
    const n = noise2(u * 2.2, seed) * 0.5 + 0.5; // 0…1
    const y = baseY - h * env * (0.55 + 0.45 * n);
    ctx.lineTo(u * w, y);
  }
  ctx.lineTo(w, baseY);
  ctx.closePath();
}
```

**怎么用**：画 8–12 层，从后往前，每层 `h` 递减、颜色向背景色靠拢（不是简单调透明度，是**在色相上往背景混**）。层数比细节重要。

## 2. 手绘线：三条规则

**来源**：[rough](https://github.com/rough-stuff/rough)（MIT）的 `src/renderer.ts`
**要点**：手抖不是加噪，是三条几何习惯——① 偏移沿法线、**两端小中间大**；② 描**两遍**，两遍偏移不同，交点自然出头；③ 端点**过冲**一点点。

```js
function handLine(ctx, a, b, { rough = 1.6, passes = 2, rnd }) {
  const dx = b.x - a.x, dy = b.y - a.y;
  const len = Math.hypot(dx, dy) || 1;
  const nx = -dy / len, ny = dx / len;          // 法线方向

  for (let p = 0; p < passes; p++) {
    const n = Math.max(3, Math.round(len / 40));
    ctx.beginPath();
    for (let i = 0; i <= n; i++) {
      const u = i / n;
      const env = Math.sin(Math.PI * u);         // 两端 0、中间 1  ← 规则①
      const off = (rnd() - 0.5) * 2 * rough * env;
      const over = (i === 0 || i === n) ? (rnd() - 0.5) * rough * 2.2 : 0; // ← 规则③
      const x = a.x + dx * u + nx * off + (dx / len) * over;
      const y = a.y + dy * u + ny * off + (dy / len) * over;
      i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
    }
    ctx.stroke();                                 // ← 规则②：整条再来一遍
  }
}
```

**怎么调**：`rough` 按画布宽取 `宽 × 0.0015`（1080 宽 → 约 1.6）。想把"记号笔"变成"粉笔"，改成 `passes = 1` 并且**在中间随机断掉几段**（留缝）；想要"钢笔"，`passes = 1`、`rough` 减半。

## 3. 沿时间连续演化的烟

**来源**：[simplex-noise.js](https://github.com/jwagner/simplex-noise.js)（MIT）的 4D 噪声 + [FastNoiseLite](https://github.com/Auburn/FastNoiseLite)（MIT）的分形叠加
**要点**：把**时间当第四维**。每帧不是"重新随机"，而是在同一个 4D 场里沿 w 轴前进一步，于是帧与帧之间天然连续。

```js
// n4(x, y, z, w)：4D 噪声，返回 -1…1
function fbm4(n4, x, y, t, octaves = 4) {
  let amp = 0.5, freq = 1, sum = 0, norm = 0;
  for (let i = 0; i < octaves; i++) {
    sum  += amp * n4(x * freq, y * freq, 0, t * freq * 0.6);
    norm += amp;
    amp  *= 0.5;
    freq *= 2;
  }
  return sum / norm;
}

// 用在轮廓上：每一层的横向偏移由噪声驱动（层数固定为 3）
function steamDrift(n4, u, layerIndex, timeSec, amp) {
  // u：沿轮廓的位置（0 底 → 1 顶）；layerIndex：第几层（0/1/2）
  // 偏移在底部为 0、越往上越大（× u），所以底边不会被推开
  return fbm4(n4, u * 1.8, layerIndex * 4.3, timeSec, 4) * amp * u;
}
```

**必须做的两件事**：
1. 频率按**短边**归一：`freq = k / Math.min(w, h)`。否则同一套参数在 1080×1920 上会被拉长。
2. `t` 用**秒**不用帧号。掉帧、补帧、改帧率时，画面才对得上。

## 4. 一个落点音的参数模板

**来源**：[jsfxr](https://github.com/chr15m/jsfxr)（Unlicense）的参数语义 · [rfxgen](https://github.com/raysan5/rfxgen)（Zlib）
**要点**：波形定"材质"，包络定"重量"，时长定"是什么"。**先把时长和频率范围定死，再去调音色**，否则永远调不出来。

| 参数 | 值 | 说明 |
|---|---|---|
| 波形 | `square`（方波） | 硬、脆，像纸/塑料。木/布换成 `sawtooth`，金属/沙换成 `noise` |
| 起始频率 | 800–2000 Hz | **低于 500Hz 手机放不出**，等于没做 |
| 滑音 | −600 ~ −1200 Hz | 向下滑=落下感；向上滑=弹出感 |
| 振幅衰减 | 指数，几乎到底 | 线性衰减听起来像被掐断 |
| 时长 | **60–120 ms** | 超过 200ms 就变成"音效"，会拖慢节奏 |
| 占空比 | 0.3–0.4 | 越小越"薄"，越大越"闷" |
| 音量 | 比人声低 6–8 dB | 落点音是垫的，不是主角 |

```js
// 批量产变体：同一模板，只动两个数
const variants = Array.from({ length: 8 }, (_, i) => ({
  wave: 'square',
  p_start: 1200 + i * 90,          // 音高微差
  p_slide: -800 - i * 40,
  p_decay: 0.05 + i * 0.004,
  p_dur:   0.075 + i * 0.005,
  duty:    0.35,
}));
```

**节奏规则**：落点音比动作完成**早 0–1 帧**。人耳对"声音早到"的容忍度远高于"声音晚到"——晚 80ms 就会觉得"没对上"。

## 补充：多层同位叠加消硬边

**来源**：实测（不属于任何仓库），但这是上面几个节点都用得到的收尾技巧。

用单层渐变做柔边时，渐变的两侧会在轮廓上留下一条**硬边**（看着像一根竖直光柱）。用模糊去补，代价是每帧多几十毫秒 × 几千帧。

正确做法是**同一条轮廓画三遍，宽度不同、权重不同**：

```js
const PASS = [
  [2.10, 0.15],   // 最宽、最淡
  [1.42, 0.32],
  [1.00, 1.00],   // 本体
];
// 每层按各自宽度算左右边缘，叠起来 → 硬边被"宽度差"抹掉，没有任何模糊
```

**关键**：渐变第一档必须从 `alpha 0` 起步。第一档就给浓度，会点亮轮廓底边的那条水平线，看起来像"贴了一块白塑料片"。

## 共同前提（比这四段代码都重要）

1. **不要用 `Math.random()`。** 用可播种 PRNG（`alea` / `mulberry32` / `xoshiro`）。逐帧渲染时，第 900 帧的随机数必须每次一样，否则重渲一次画面全变、和音轨对不上。这一条违反了，上面所有技巧都白搭。

```js
function mulberry32(seed) {
  return function () {
    seed |= 0; seed = (seed + 0x6D2B79F5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

2. **所有像素参数换成"画布宽的倍数"。** 写死像素的那一刻，这套代码就只能出那一种尺寸的片。

3. **画布直接开目标尺寸**（竖屏 1080×1920），不要渲染完再裁——线宽和抖幅都是按像素算的，裁完全毁。
