| | 50 仓 | 本库（24 仓） |

| 交付物 | 写给别人看的**话**（提示词、镜头词表、分镜模板） | 自己跑的**代码**（画法、生成器、合成器） |


两边已经互相指向：50 仓的 README 顶部有本库入口，它的「路线 C」也把出口放在这里。两个库是**同一目录下并列的两个文件夹**（`AI视频提示词素材库_50仓/` 与 `代码视觉与音效素材库_24仓/`）；目前只有本库推到了远端，所以 50 仓那一侧还是本地目录，别指望在这里点到它。

## 四、为什么分成「形 / 场 / 声」

不是按语言、也不是按星数分，是按**你在画面上动笔的顺序**分：

1. **形（01）** —— 画面上那个东西的轮廓怎么来。山、树、人、线稿、手写线、笔序。这一层决定"像不像"。
2. **场（02）** —— 东西站在什么环境里。街道、地图、雾、光、材质。这一层决定"在不在那个地方"。
3. **声（03）** —— 画面动一下，耳朵要听到什么。这一层最容易被拖到最后，也最容易毁掉前面两层。

三层的关系是**同一套代码**：01 产出的 SVG/Canvas 图形，02 给它底与光，03 按时间码对齐。所以本库的节点都能串在一条管线里，不是各自独立的工具清单。

判断一个仓值不值得收，用四条：
1. 交付物是**可读的实现**（源码/着色器/音色/采样），不是宣传页、不是成片；
2. 能**关掉网络跑**（或至少能看懂并重写），不依赖某个在线服务；
3. 有**明确的画法主张**（分层、噪声、约束求解、参数化），而不是"又一个绘图 API 封装"；
4. **许可允许商用**或至少明确到"能抄思路、不能抄代码"。

## 五、六条硬规矩（用这些仓时始终记着）

1. **许可先看再抄。** 本库有 3 个仓是 GPL/AGPL（`prettymaps`、`texturelab`、以及 `SuperCollider` 的引擎部分），1 个仓是**保留所有权利**（`thebookofshaders`）。这四个只能抄思路，不能把代码或着色器原文搬进客户交付物。详见 `00_起点/全仓清单.md` 的许可列。
2. **同种子必须同帧。** 所有程序化绘制引入随机时，一律走可播种 PRNG（`simplex-noise.js` 的 `alea`、`shan-shui-inf` 的 `noiseSeed`）。逐帧渲染 1800 帧时，第 900 帧的随机数必须每次一样，否则重渲就对不上音轨。
3. **画布直接开 1080×1920。** 不要横屏渲染再裁——裁完字号和线宽全毁，尤其手绘抖线的抖幅是按像素算的。
4. **硬边不许用模糊消。** 需要柔边（烟、光、影）时用"多层同位叠加 + 宽度差"，不要 `shadowBlur` / 高斯模糊：一帧几十毫秒，乘上几千帧就是几个小时。
5. **素材不要进仓库。** 采样、音色、贴图只记来源与许可，用时现取（见 `00_起点/需求速查.md` 末节）。仓库只放"怎么画"和"去哪拿"。
6. **别在节点里做二次封装。** 本库是参考库，不是依赖库。抄的时候直接把那几十行搬进你自己的渲染器，比装一个包更可控。

## 六、使用与维护

- 所有 `.md` 都是纯文本，可以直接拷进 Claude Code / Cursor / WorkBuddy 当 Skill 或长指令使用。
- **改完文档跑一次 `node check.mjs`**：它守五件事——15 个节点编号连续、每张卡五节齐全且带「目录（已核对）」、相对链接不断、正文引用的节点号都存在、全仓清单 24 行 / 18 个节点标记 / 分栏 10-7-7。断链这一项做过反向验证（故意加一条假链接，它会红）。
- 每个仓的星数、许可、最近提交日期来自 **2026-10-30** 的 API 快照与许可原文核对；建议每季度用 `00_起点/全仓清单.md` 批量复查一次是否仍在维护。
- 表格里的「参考用途」是**给你自己看的取舍依据**，不是仓库官方描述，取舍标准写在第四节。
- 本库只做索引与提炼，代码版权归各仓库作者，抄之前看各自的 LICENSE。
- 判错过一次就要记下来：本库第一批结论里有 4 处是"凭项目印象写的"，后来读源码/许可原文推翻了。更正记录在 `00_起点/全仓清单.md` 末尾，留着提醒后来的人——**没读到源码就别描述实现**。
